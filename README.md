# MyHomeLib

**Українська** · [English](README.en.md)

## Що це таке

MyHomeLib — настільна програма для Windows, яка дає змогу каталогізувати власну колекцію файлів електронних книг: книги розкладаються по авторах, серіях і жанрах, шукаються за довільним набором умов і відкриваються в тій програмі для читання, яку ви налаштували.

Окрім власних колекцій, MyHomeLib працює як клієнт бібліотек на движку Лібрусек — зокрема Флібусти та подібних сайтів. Каталог такої бібліотеки підключається з файлу INPX, після чого книги можна шукати й переглядати локально, а завантажувати з сервера лише ті, які справді потрібні.

Книги зберігаються у форматах FB2 (окремі файли або zip-архіви), FBD та будь-яких інших; метадані колекції — у базі SQLite.

## Можливості

**Колекції**

- Кілька колекцій одночасно з миттєвим перемиканням між ними.
- Типи колекцій: локальна чи мережева, власна чи підключена зовнішня бібліотека, FB2 чи не-FB2.
- Майстер створення колекції: порожня колекція, побудова з файлу INPX або підключення наявного файлу `.hlc2`.
- Оновлення колекції з мережі та вручну, синхронізація тек і файлів, обслуговування бази даних.
- Копіювання книг між FB2-колекціями, експорт колекції у формат INPX.

**Книги**

- Імпорт FB2 (файли й архіви), FBD та книг у інших форматах; пакетний імпорт з INPX.
- Дерева перегляду за авторами, серіями та жанрами з алфавітними фільтрами (кирилиця й латиниця).
- Пошук за автором, назвою, серією, жанром, ключовими словами, анотацією, ім'ям файлу, датою додавання, мовою та оцінкою бібліотеки — з умовами виду `%текст%`, `="точне значення"`, `<`, `>`, `<>`, `OR` — і збереженням наборів умов у пресети.
- Групи та обране, рейтинг, прогрес читання й рецензії; експорт та імпорт цих даних користувача окремо від каталогу (прив'язка за LibID).
- Завантаження книг з онлайн-бібліотеки, читання у зовнішніх програмах за типом файлу.
- Надсилання книг на пристрій з конвертацією: fb2mobi, fb2epub, fb2lrf, fb2pdf; шаблони імен файлів і підтек.
- Користувацькі скрипти після надсилання на пристрій з підстановками `%DEST%`, `%TMP%`, `%FILENAME%` та іншими.
- Редагування описів книг і авторів, експорт списку книг у HTML.

**AI-асистенти**

- Разом з програмою встановлюється MCP-сервер (`MHLMcpServer.exe`), який відкриває колекцію асистентам на кшталт Claude: пошук книг, перегляд авторів, серій і жанрів, зміст і текст книги, пошук усередині книги. Працює лише на читання й не потребує запущеної MyHomeLib. Як підключити — у довідці, розділ «MCP-сервер для AI-асистентів».

## Встановлення

Готові інсталятори для 64- та 32-розрядної Windows публікуються на сторінці [Releases](https://github.com/OleksiyPenkov/MyHomeLib/releases). Якщо потрібного файлу там немає, інсталятор можна зібрати самостійно — див. `Installer/build_installer.cmd` (потрібен [Inno Setup](https://jrsoftware.org/isinfo.php)).

Вимоги: Windows 10 або новіша. Місце на диску визначається переважно розміром колекцій книг, а не самою програмою.

Програма підтримує portable-режим: якщо поруч із виконуваним файлом лежить `myhomelib2.ini`, налаштування читаються з нього, а не з `%APPDATA%`. Це дає змогу тримати програму разом з колекцією на зовнішньому носії.

## Швидкий старт

1. Встановіть програму й запустіть її.
2. **Колекція → Створити** — майстер запитає тип колекції, теку з книгами й формат файлів.
3. Наповніть колекцію: імпортуйте наявні файли книг з диска або побудуйте каталог з файлу INPX онлайн-бібліотеки.
4. Переглядайте дерева авторів, серій і жанрів, шукайте книги на вкладці «Пошук», відкривайте їх у своїй програмі для читання або надсилайте на пристрій.

Докладніше — у вбудованій довідці.

## Довідка

Повна довідка українською (55 сторінок) постачається разом з програмою. Клавіша **F1** контекстно-залежна — відкриває у браузері саме ту сторінку, яка відповідає активному вікну чи вкладці. Вихідні файли довідки — у теці [`Program/Help/`](Program/Help/); [`index.html`](Program/Help/index.html) є змістом і точкою входу.

## Збірка з вихідного коду

**Потрібно:**

- Delphi 13 (RAD Studio 37.0);
- [VirtualTreeView](https://github.com/JAM-Software/Virtual-TreeView) (встановлюється через GetIt);
- Konopka Signature VCL Controls (`BonusKSVC` 8.0.1, теж через GetIt);
- `C:\Windows\System32` у змінній `PATH` — подія after-build викликає `robocopy`, і без цього збірка падає на `copy_help.cmd`.

**Збирайте лише через груповий проєкт** `Program\MHL.groupproj` — він містить пакет компонентів, DLL з іконками, головну програму та MCP-сервер у правильному порядку:

```
cmd.exe /c "set BDS=C:\Program Files (x86)\Embarcadero\Studio\37.0&& set BDSCOMMONDIR=C:\Users\Public\Documents\Embarcadero\Studio\37.0&& C:\Windows\Microsoft.NET\Framework\v4.0.30319\msbuild.exe Program\MHL.groupproj /t:Build /p:Config=Release /p:Platform=Win64 /nologo /v:minimal"
```

Для 32-розрядної збірки замініть `/p:Platform=Win64` на `/p:Platform=Win32`. Основна платформа — Win64; збирайте її першою, але перед випуском мають проходити обидві.

> **Не запускайте msbuild безпосередньо на `Program\MyhomeLib.dproj`.** Це переписує файл проєкту й піднімає імпорт `CodeGear.Delphi.Targets` вище груп конфігурації, після чого будь-яка наступна збірка — зокрема й групова — падає з `F2613 Unit 'SysUtils' not found`. Груповий проєкт файл не переписує.

**Результат збірки:** `Program/OUT/Bin64/` та `Program/OUT/BIN/` (виконувані файли), `Program/OUT/Units/` (DCU). Подія after-build кладе поруч з exe теку довідки та `Resources\Icons\<платформа>\MHLIcons.dll` — усі іконки програма завантажує з цієї DLL під час виконання.

## Структура репозиторію

```
Program/
  MyHomeLib.dpr        головний проєкт
  MHL.groupproj        груповий проєкт (компоненти + іконки + програма + MCP-сервер)
  Forms/               форми VCL (frm_*.pas), Forms/Editors/ — діалоги редагування
  DataModules/         dm_user.pas — глобальний модуль даних (налаштування, системна БД)
  Units/               ядро: глобальні типи, налаштування, інтерфейси, помічники
  DAO/                 шар доступу до даних (абстрактні класи), DAO/SQLite/ — реалізація
  ImportImpl/          потоки імпорту книг (FB2, FBD, INPX) і форми прогресу
  DwnldImpl/           потоки завантаження книг
  UtilsImpl/           синхронізація, експорт на пристрій, оновлення колекції
  Wizards/             майстер створення колекції
  Help/                довідка українською (HTML)
  Resources/           іконки, зображення
Components/
  MHLComponents/       пакет компонентів часу розробки (BookTreeView, розбір FB2, архіви)
Utils/                 допоміжні утиліти (див. нижче)
Installer/             скрипти Inno Setup
tools/                 допоміжні скрипти розробки
docs/                  специфікації та плани розробки
```

## Утиліти

- **`Utils/MHLMcpServer`** — MCP-сервер (Model Context Protocol) лише для читання, який відкриває колекцію MyHomeLib клієнтам на кшталт Claude: пошук книг, перегляд авторів, серій і жанрів, зміст і текст книги, пошук усередині книги. Лінкується з тим самим шаром DAO, що й програма, тож бачить ті самі колекції. На відміну від решти утиліт, постачається інсталятором і лягає поруч з `MyHomeLib.exe`. Опис для користувачів — у довідці ([`mcp_server.html`](Program/Help/mcp_server.html)), технічний — у [`Utils/MHLMcpServer/README.md`](Utils/MHLMcpServer/README.md).
- **`Utils/MHLSQLiteConsole`** — окрема консоль SQLite для роботи з базами колекцій напряму.
- **`Utils/MHLSQLiteExt`** — розширення SQLite мовою C++ з користувацькими функціями, які використовує програма.
