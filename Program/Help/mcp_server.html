MCP-сервер для AI-асистентів

Що це таке

Разом із програмою встановлюється окремий виконуваний файл MHLMcpServer.exe — MCP-сервер, який відкриває вашу бібліотеку для AI-асистентів. MCP (Model Context Protocol) — це узгоджений спосіб, у який такі помічники звертаються до зовнішніх даних. Підключивши сервер до асистента, ви зможете питати про власну колекцію звичайною мовою: попросити знайти книги певного автора, нагадати, що саме входить до серії, переказати зміст книги або знайти в ній потрібний фрагмент.

Сервер не має власного вікна і не працює у фоні постійно: асистент сам запускає його тоді, коли йому потрібні дані, і закриває, коли розмова завершилася. Окремо запускати MHLMcpServer.exe подвійним клацанням не потрібно й немає сенсу — без асистента він просто чекає команд і нічого не показує.

Сервер працює з тими самими колекціями й тією самою системною базою, що й сама MyHomeLib, і бачить їх однаково — окремо налаштовувати шляхи чи вибирати колекцію не потрібно.

Що сервер уміє

Робота з каталогом: перелічити наявні колекції, авторів, серії та жанри, знайти книги за назвою, автором, серією, жанром, мовою, ключовим словом, анотацією чи рейтингом, а також показати повний опис окремої книги — так само, як його показує панель відомостей у головному вікні.

Робота з текстом книги: показати зміст (перелік розділів), видати текст книги або його частину й знайти в книзі задане слово чи фразу. Ці три можливості працюють лише з книгами у форматі FB2 — і з окремими файлами, і з тими, що лежать в архівах.

Перелічувати ці можливості вручну не доведеться: асистент запитує їх у сервера сам, щойно з'єднається з ним.

Як підключити

Спосіб підключення залежить від асистента, але майже всі використовують той самий формат опису — файл .mcp.json, у якому вказано, що саме запускати. Додайте до нього такий запис:

{
  "mcpServers": {
    "myhomelib": {
      "command": "C:\\Program Files\\MyHomeLib\\MHLMcpServer.exe",
      "args": []
    }
  }
}

Шлях має вказувати на теку, у яку встановлено MyHomeLib. Наведений вище — типовий для 64-розрядної версії; якщо під час встановлення ви вибрали іншу теку або встановили 32-розрядну версію, підставте свій шлях. Зверніть увагу на подвоєні зворотні скісні риски: у форматі JSON шлях записують саме так.

Ніяких параметрів запуску, ключів чи власних налаштувань сервер не має — усе інше він визначає сам. Де саме розміщується .mcp.json і як його перечитати, дивіться в довідці свого асистента.

Сервер лише читає

Сервер працює винятково на читання: він не змінює ні бази даних, ні файлів книг, не додає, не видаляє й не редагує записи. Хоч би про що ви попросили асистента, колекція залишиться такою, якою була, тож підключати сервер безпечно навіть до великої й ретельно впорядкованої бібліотеки.

Сама MyHomeLib для цього не потрібна: сервер читає колекції й тоді, коли програму закрито. Тримати головне вікно відкритим, щоб асистент міг відповідати на запитання, не треба.

Обмеження

Зміст, текст і пошук усередині книги доступні лише для книг у форматі FB2. Для книг в інших форматах сервер повідомить, що формат не підтримується; відомості з каталогу (автор, серія, жанр, анотація) при цьому доступні для всіх книг незалежно від формату.

Поки програма зайнята тривалою дією з колекцією — імпортом, оновленням чи обслуговуванням бази — сервер не зможе її прочитати й повідомить, що колекція зайнята. Це тимчасово: щойно дія завершиться, запити знову працюватимуть. Просто зачекайте й попросіть асистента повторити.

Пошук за назвою, автором чи іншим текстовим полем шукає точний збіг частини рядка, без урахування регістру. Він не виправляє помилок і не добирає близькі за написанням слова, тож у запиті варто вживати ту саму форму слова, що й у самій колекції.

Довгі переліки сервер видає частинами й обмежує їхній розмір, щоб відповідь не розросталася нескінченно. Якщо потрібне продовження, асистент запросить наступну частину сам.

Текст книги, з якою вже працювали, сервер зберігає в теці %LOCALAPPDATA%\MyHomeLib\McpCache, щоб наступного разу відповідати швидше. Ця тека містить лише проміжні дані: її можна видалити будь-коли, сервер просто підготує текст наново.
