Експорт колекції у формат INPX

Команда «Колекція» → «Експорт» → «Експортувати в inpx» зберігає весь каталог активної колекції у файл-архів формату INPX (див. Основні терміни) — той самий формат, з якого створюють нову колекцію і яким оновлюють наявну.

Що потрапляє у файл

Для кожної книги колекції в архів записується один рядок бібліографічного опису: автори, жанри (кодами — FB2 чи внутрішніми, залежно від того, FB2-колекція це чи ні), назва, серія й номер у ній, ім'я файлу, розмір, стабільний ідентифікатор книги (LibID), позначка видалення, розширення, дата, мова та ключові слова. Крім цього, до архіву додаються файл версії даних, опис структури полів і службовий запис із назвою, файлом, типом, описом, адресою та скриптом підключення самої колекції.

Особисті дані користувача — рейтинги, прогрес читання, рецензії, анотації, належність до груп — у файл INPX не потрапляють. Для їх експорту призначена окрема команда, див. Експорт та імпорт даних користувача.

Чого у файлі немає

Файл INPX — це лише каталог, без самих файлів книг: розмір експортованого архіву не залежить від того, скільки важать книги колекції.

Для чого це потрібно

Експортований файл INPX можна передати іншому користувачеві MyHomeLib як готовий каталог для створення нової колекції, використати як джерело даних для оновлення схожої колекції, або зберегти як текстовий знімок каталогу колекції на певний момент часу — незалежно від самої бази .hlc2.
