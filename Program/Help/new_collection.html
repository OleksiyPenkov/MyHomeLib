Створення колекції

Команда «Колекція» → «Створити нову колекцію» (Ctrl+N) запускає майстер, який і створює нову порожню колекцію, і підключає наявну, і будує колекцію з файлу INPX. Набір кроків, які покаже майстер, залежить від вибору, зробленого на другому кроці — нижче кроки наведено в тому порядку, у якому вони фактично йдуть одне за одним; кроки, позначені як умовні, з'являються лише для певного вибору.

Крок 1. Вітання

Вступна сторінка майстра створення колекції MyHomeLib — лише пояснювальний текст, полів для заповнення тут немає.

Крок 2. Тип колекції

Тут вибирають, що саме робитиме майстер:

  • Нова порожня колекція — створити порожню колекцію, яку потім наповнюють імпортом книг;
  • Існуюча колекція (hlc2) — підключити вже наявний файл колекції;
  • Колекція з файлу inpx — створити й одразу наповнити колекцію з файлу-каталогу INPX (див. Основні терміни).

Крок 3. Джерело INPX (лише для «Колекція з файлу inpx»)

Показується, тільки якщо на попередньому кроці вибрано «Колекція з файлу inpx». Тут указують, звідки взяти файл INPX:

  • Локальний файл INPX — файл, який уже є на диску користувача (кнопка «Вибрати» відкриває діалог вибору файлу);
  • Завантажити із сайту — список готових колекцій (lib.rus.ec, Флібуста тощо), джерела для якого беруться з файлу collections.ini (див. Встановлення); файл INPX буде завантажено із сервера. Цей варіант доступний, лише якщо список не порожній.

Тип майбутньої колекції (власна чи зовнішня, локальна чи мережева, FB2 чи не-FB2) визначиться пізніше — з даних, збережених усередині самого файлу INPX; див. Типи колекцій.

Крок 4. Завантаження файлу INPX (лише за вибору «Завантажити із сайту»)

Показує хід завантаження вибраного файлу INPX із сервера: швидкість і обсяг завантаженого. Кроку немає, якщо файл INPX береться з локального диска.

Крок 5. Назва колекції

Спільний крок для всіх варіантів: назва колекції, файл колекції та тека з книгами.

  • Назва колекції — довільне ім'я, під яким колекція показуватиметься в списках і меню; має бути унікальним серед підключених колекцій;
  • Файл колекції — шлях до файлу .hlc2. Для нової колекції та колекції з INPX указують, де створити файл (кнопка «Вибрати»); для підключення наявної колекції — де знайти вже наявний файл;
  • Папка з книгами — тека, де зберігатимуться (або вже зберігаються) файли книг цієї колекції.

Якщо колекція створюється з файлу INPX, назву й файл колекції майстер одразу підставляє з даних, збережених у самому INPX, — це можна виправити вручну.

Крок 6. Формат файлів (лише для «Нова порожня колекція»)

Показується, тільки якщо на кроці 2 вибрано «Нова порожня колекція». Визначає вміст майбутньої колекції:

  • Книги у форматі FictionBook — колекція зберігатиме книги FB2/FB2.ZIP, зі стандартним деревом жанрів FB2;
  • Книги в інших форматах (fbd, pdf, djvu) — колекція для книг не-FB2, зі своїм деревом жанрів (наступний крок дозволить вибрати файл жанрів).

Прапорець «Розпочати імпорт книг після створення колекції» (за умовчанням увімкнено, доступний лише для FB2) одразу після створення колекції відкриває імпорт книг — див. Імпорт книг у форматі FB2.

Крок 7. Файл опису жанрів (лише для нової не-FB2-колекції)

Показується, тільки якщо створюється нова порожня колекція з форматом «Книги в інших форматах». Для нової FB2-колекції, підключення наявної та створення з INPX файл жанрів вибирається автоматично, і цей крок не з'являється.

  • За замовчуванням — використати файл опису жанрів, що постачається з програмою;
  • Спеціальний файл жанрів — указати свій файл (кнопка «Вибрати»).

Прапорець «Запустити імпорт після створення колекції» тут повторює той самий вибір, що й на кроці формату файлів. Про самі файли жанрів — див. Списки жанрів.

Крок 8. Хід виконання

Спільний для всіх варіантів крок: тут майстер власне створює або підключає колекцію в системній базі, а для варіантів з INPX — одразу після цього імпортує дані з файлу INPX (з журналом подій і смугою прогресу). На цьому кроці доступна лише кнопка «Відміна» — кнопок переходу на попередній чи наступний крок тут немає; якщо реєстрацію колекції завершити не вдалося, майстер лишається на цій сторінці й пропонує зберегти журнал помилок.

Крок 9. Завершення

Підсумкова сторінка: колекцію вже створено (чи підключено), і після закриття майстра нею одразу можна користуватися.
