Типи файлів і програми для читання

Розділ «Типи файлів» діалогу налаштувань (див. Налаштування програми) — таблиця відповідності «розширення файлу → програма для перегляду», якою користується команда «Читати»; докладніше про сам механізм вибору читалки — у розділі Читання книг.

Список

Таблиця має дві колонки — «Розширення» і «Шлях» — і керується трьома кнопками під нею:

Додати
Відкриває невелике вікно «Додавання типу файлів» із полями «Тип:» (розширення, без крапки — регістр не важливий) і «Шлях:» (повний шлях до програми-читалки; кнопка «Огляд...» відкриває стандартний діалог вибору файлу). Розширення обов'язкове — без нього запис не додасться; якщо таке розширення в списку вже є, з'явиться повідомлення про це, і запис також не додасться.
Змінити
Відкриває те саме вікно для вибраного рядка (або подвійний клац по рядку); можна змінити як шлях, так і саме розширення.
Видалити
Прибирає вибраний рядок зі списку без додаткового підтвердження.

Якщо для розширення читалки немає

Список необов'язково має покривати всі типи файлів у колекції: для розширення, якого в таблиці немає, MyHomeLib просто передає файл на відкриття тій програмі, яку для цього розширення визначила сама Windows (звичайна файлова асоціація) — так само, як і для запису з порожнім полем «Шлях».

Вбудована читалка

MyHomeLib не має власної вбудованої читалки — «Читати» завжди запускає окрему програму. Інсталятор лише кладе поруч читалку AlReader і під час першого запуску (поки список читалок ще порожній) сам заповнює таблицю нею для розширень fb2, doc, txt, htm і html; для інших типів файлів (PDF, DjVu тощо) типовий запис не додається. Цей початковий набір — лише зручний стартовий стан таблиці: його можна вільно редагувати чи видаляти, як і будь-який інший рядок.
