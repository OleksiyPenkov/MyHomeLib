MCP server for AI assistants

What it is

A separate executable, MHLMcpServer.exe, is installed together with the program: an MCP server that opens your library to AI assistants. MCP (Model Context Protocol) is an agreed way for such assistants to reach external data. Connect the server to an assistant and you can ask about your own collection in plain language: find the books of a particular author, recall what a series consists of, summarize a book or find a passage in it.

The server has no window of its own and does not sit running in the background: the assistant starts it when it needs data and closes it when the conversation is over. There is no point in starting MHLMcpServer.exe yourself by double-clicking it — without an assistant it simply waits for commands and shows nothing.

The server works with the same collections and the same system database as MyHomeLib itself, and sees them in the same way — there are no paths to configure and no collection to choose.

What the server can do

Catalog work: list the collections, authors, series and genres you have; find books by title, author, series, genre, language, keyword, annotation or rating; and show the full description of a single book, exactly as the info panel in the main window shows it.

Book text work: show the table of contents (the list of chapters), return the text of a book or part of it, and find a given word or phrase in a book. These three capabilities work only with books in FB2 format — both with standalone files and with files inside archives.

You will not have to list these capabilities by hand: the assistant asks the server for them itself as soon as it connects.

How to connect it

How you connect it depends on the assistant, but nearly all of them use the same description format — a .mcp.json file that says what to start. Add an entry like this to it:

{
  "mcpServers": {
    "myhomelib": {
      "command": "C:\Program Files\MyHomeLib\MHLMcpServer.exe",
      "args": []
    }
  }
}

The path has to point at the folder MyHomeLib is installed in. The one above is the usual one for the 64-bit version; if you chose a different folder during installation, or installed the 32-bit version, substitute your own path. Note the doubled backslashes: that is how a path is written in JSON.

The server has no command-line parameters, switches or settings of its own — it works everything else out for itself. Where the .mcp.json file lives and how to make the assistant re-read it are covered in your assistant's own documentation.

The server only reads

The server works strictly read-only: it changes neither the databases nor the book files, and it adds, deletes and edits nothing. Whatever you ask the assistant for, the collection stays exactly as it was, so it is safe to connect the server even to a large and carefully curated library.

MyHomeLib itself is not needed for this: the server reads the collections with the program closed as well. You do not have to keep the main window open for the assistant to answer questions.

Limitations

The table of contents, the text and the search inside a book are available only for books in FB2 format. For books in other formats the server reports that the format is not supported; catalog information (author, series, genre, annotation) is available for every book whatever its format.

While the program is busy with a long operation on a collection — an import, an update or database maintenance — the server cannot read it and will report that the collection is busy. This is temporary: as soon as the operation finishes, requests work again. Just wait and ask the assistant to try again.

Searching by title, author or any other text field looks for an exact match on part of the string, ignoring case. It does not correct mistakes and does not pick up words spelled similarly, so it is worth using the same form of a word in your request as the one in the collection itself.

The server returns long lists in chunks and limits their size, so that an answer cannot grow without end. If there is more to come, the assistant requests the next chunk itself.

The text of a book you have already worked with is kept by the server in the %LOCALAPPDATA%\MyHomeLib\McpCache folder, so that it can answer faster next time. That folder holds intermediate data only: you can delete it whenever you like, and the server will simply prepare the text again.
