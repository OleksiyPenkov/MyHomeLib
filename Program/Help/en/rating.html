Rating and read status

My rating

Your personal rating of a book, one to five stars — the Book → Rating submenu, or the same submenu in the book list context menu (for details see Book menu and Context menus). The Clear item in that same submenu removes the rating. If several books are checked, the rating is applied to all of them at once; if none are checked, only to the current one (see Selecting and marking books).

This is not the same as the library Rating you see in a list column or in a search field: that one comes from outside (from the online library) and cannot be edited in MyHomeLib.

Mark as read

This is a toggle, not a one-way mark. The Mark as read command looks at the book's current reading progress: if it is 0%, the command sets it to 100% ("the book has been read"); at any other value, including a book already read to 100%, it resets the progress to 0%. In other words, applying the command a second time to a partly or fully read book removes the progress mark rather than confirming it.

MyHomeLib itself has no slider or other way to set an intermediate progress percentage — the Mark as read command only switches between 0% and 100%. Intermediate progress values can only arrive with data from outside (when an online collection is updated, for instance).

Where these values are stored

MyHomeLib keeps the rating and the reading progress in the collection's own database — unlike groups, which live in the shared system database (user.dbs2); see Key terms and Groups and favorites. The reading progress is additionally mirrored into the system database, so that the same mark is visible when you view the book through a group.
