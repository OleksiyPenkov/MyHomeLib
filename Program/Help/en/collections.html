Working with collections

MyHomeLib does not work with one single library but with a set of collections — separate book databases, each with its own .hlc2 file and, as a rule, its own book folder on disk. A collection can be created empty, connected from a .hlc2 file you already have, or built from an INPX file; for details see Creating a collection.

Several collections at once

You can connect as many collections as you like — your own library, a local copy of lib.rus.ec or Flibusta, a separate collection for books that are not in FB2 format, and so on. Only one of them is in use at any given moment: the active collection, whose authors, series, genres and books are the ones the main window shows.

The list of collections and where it is kept

The list of connected collections, their properties (name, path to the file, book folder and so on) and your user data (groups, Favorites among them, ratings, reading progress) are all stored not inside the collection files but separately, in the system database user.dbs2. For where exactly that file lives, see FAQ. Deleting or damaging user.dbs2 means losing the list of collections and all of your user data, although the collection files and the books themselves do not disappear with it — see Deleting a collection.

Switching between collections

To make another connected collection the active one, use the Collection → Select collection submenu — it lists every collection except the current one. For more about the Collection menu see Collection menu.

Collection statistics

The Collection → Statistics command opens a window with a brief summary of the active collection: its name, creation date, data version and description, along with the number of authors, books and series it holds.
