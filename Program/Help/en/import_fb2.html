Importing FB2 books

The Collection → Import → FB2 and fb2.zip files command scans files on disk and creates records for them in the current (active) local FB2 collection. The command is available for local FB2 collections only.

Where the files come from

The source depends on the Enable sorting during import option (see File sorting):

  • with sorting on, the program scans the separate import folder set in the settings, copies the files it finds into the collection folder, spreads them across subfolders and renames them according to the file name and folder templates;
  • with sorting off, the program scans the collection folder itself: the files have to be placed there in advance (by hand, say, or by another program), and during the import they are neither copied nor renamed — they are simply added to the catalog where they already are.

The import runs in two passes: first the standalone .fb2 files, then the .fb2.zip archives (every FB2 file inside an archive is read exactly like a standalone file; if sorting is on and the archive holds exactly one FB2 file, the archive itself is renamed).

What is read from the file

From the FB2 XML structure (the description/title-info section) the program takes the author or authors, the title, the genre list, the language, the keywords, the series together with the book's number in it, and the annotation. You can edit the same data by hand afterwards — see Editing book descriptions.

Duplicates

Before adding a book, the program checks whether the collection already holds a record with the same file name in the same folder. If it does, the file counts as already imported and is skipped: no new record is created, and the existing record is left untouched.

Import progress and errors

A window with a progress bar is shown while the files are scanned and imported. Files that could not be parsed as valid FB2 (a damaged or non-conforming structure) are not added to the catalog; each one gets a line in the error list in that same window instead. The program keeps no separate log file for import errors — once the operation finishes, the Save button lets you save that list to a file of your choice.
