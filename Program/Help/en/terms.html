Key terms

This page explains the terms used consistently throughout the MyHomeLib help.

Collection
A separate book database (a .hlc2 file) — either a private library of your own or a connected external library. You can keep several collections at once and switch between them; more on this in Working with collections.
Collection type: local and online
An internal division of collections by the way books are stored, rather than the names you see on screen. A local collection keeps the book files on your own disk. An online (network) collection asks a library server (Flibusta, for instance) for its books and downloads them only when needed. Both are created by the collection wizard; see Collection types and Creating a collection.
INPX
The catalog file format that libraries running the Librusec engine exchange: an archive of book descriptions without the files themselves. An INPX file can be used to create a new collection or to update an existing one, and a collection of your own can be exported back to INPX; see Creating a collection and Exporting to INPX.
FB2, FB2.ZIP, FBD, non-FB2
FB2 is the main book format MyHomeLib works with; FB2.ZIP is the same file compressed into a ZIP archive. A book in any other format (PDF, DjVu, EPUB, TXT and so on) is stored by the program as non-FB2; for such a book you can create a small description file — an FBD — which is packed together with the file itself into a single archive so that the book has an author, a title and a genre just as an FB2 does. See Importing FB2 books and Importing non-FB2 and FBD books.
Group
An arbitrary named label you can attach to any books in a collection so that you can later find them together — regardless of author or series. Groups are managed on the Groups tab; see Groups and favorites.
Favorites
One of the two groups that exist in MyHomeLib from the start and cannot be deleted — the other being To read. The Favorites group is meant for books you want to set aside for quick access. Technically it uses exactly the same group machinery as an ordinary group; more on this in Groups and favorites.
Genre
A label marking a book's subject or category, taken from a standard genre list (a separate one for FB2 and for non-FB2 books). Genres are organized as a tree and are shown on the genre browsing tab; see Genre lists and Browsing: authors, series, genres.
Series
A group of books by one author or from one cycle, sharing a common name and numbered within it. Series are shown on a browsing tab of their own; see Browsing: authors, series, genres.
Device
A folder or a connected gadget to which MyHomeLib copies or converts books for reading outside the program — an e-reader or a smartphone, for instance. Devices are configured in advance with the formats they need; see Devices and export and Sending books to a device.
Reader
An external program that MyHomeLib launches to view a book of a particular format (identified by the file extension). If no reader is assigned to an extension, the program registered as the system default is used. Configured in File types and readers.
Script
An external program or batch file that MyHomeLib can optionally run right after books are sent to a device, passing the path to the files just sent among its launch parameters. Not to be confused with the connection script of an online collection (a separate property of the collection itself — see Collection properties); registered scripts are configured in Scripts, and there are examples in Script examples.
System database
The user.dbs2 file — a database shared by all collections, in which MyHomeLib stores the list and the properties of the connected collections, the groups (Favorites included), and the ratings, reading progress and notes you assign to books. Where exactly this file lives is covered in FAQ.
