Script examples

This page supplements Scripts with examples. A MyHomeLib script is not a conversion script (the program converts to LRF, EPUB, PDF and MOBI by itself, with built-in converters — see Sending books to a device) and not a script for working with an online library; it is any external program you like, launched after the books have been sent, with paths substituted into its parameters. So the examples below are not about converters but about the typical shape of such an entry.

A second copy folder (with no program at all)

The simplest entry uses no external program whatsoever, only the special value %COPY% in the Path field (see Scripts):

TitlePathOptions
Backup copy%COPY%D:\Book backup\

Choosing this entry in the list of scripts (or as the default one) makes an ordinary send to a device additionally copy the very same files into the folder named here, without launching anything else.

Open the result folder in Explorer

An entry that opens the destination folder right after a send — to check the result, or to drag the files onto the device yourself. It uses explorer.exe, the standard Windows file manager rather than any special tool, and the %DEST% substitution (see Scripts):

TitlePathOptions
Show folderexplorer.exe%DEST%

A batch file of your own

For anything more involved (renaming, a detailed log, calling a third-party device sync tool and so on) the path points at a .bat or .cmd file of your own, and the sequence of actions is written inside that file, not in the parameters field. MyHomeLib merely passes it the substituted values as command line arguments:

TitlePathOptions
My actionC:\Scripts\send_to_device.bat%DEST% %FILENAME%

Inside such a .bat file the substituted values are available as ordinary command line parameters (%1, %2 and so on); what the file does with them is entirely up to whoever wrote it — MyHomeLib only launches it.

This help gives no ready-made examples for particular third-party device sync or cloud storage programs — MyHomeLib ships none of those tools and tests none of them; supply your own path and parameters from the documentation of the program you need.
