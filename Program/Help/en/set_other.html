Behavior

The Misc section of the settings dialog (see Program settings) collects the options governing program behavior that belong to no other section.

Show books from nested genres (non-FB2)
For collections of non-FB2 books: when you view a parent genre, also show the books tagged with its subgenres and not only with the parent genre itself. It has no effect on FB2 collections — there books are always shown that way. On by default.
Minimize to tray
Pressing the window's minimize button puts MyHomeLib into the tray instead of the taskbar. Off by default.
Start downloads automatically
The download queue (see Downloading books) starts downloading the books added to it by itself, without a separate Start command. Off by default.
Allow mixed collections
Makes the actions normally offered only for FB2 collections (sending to a device with conversion to another format, in particular) available for collections of non-FB2 books as well. Off by default.
Delete books "deleted in the online library"
Applies only to online collections, during synchronization with the source library: if a book that has already been downloaded to disk is marked as deleted by the library, MyHomeLib deletes the local file along with that mark (the catalog record itself stays — see Deleting books). Off by default.
Download reviews automatically
For books in an online collection, fetch the review along with the book itself, without a separate action on your part. On by default.
Delete files when deleting books
Whether to delete the book file from disk when its record is deleted from the catalog (see Deleting books, which spells out exactly which books this happens to). Off by default.
Overwrite the FB2 header
Lets MyHomeLib rewrite the author, title, genre and series inside the FB2 file itself with the values from the collection catalog — both when sending to a device and when opening a book for reading; exactly which files and exactly when is covered in Editing book descriptions, Sending books to a device and Reading books. Off by default.

The Book title template: field below (the "Change" button beside it opens the same template editor as the device and file sorting templates; the default value is simply %t, that is, the book title unchanged) defines what actually goes into the header. If this checkbox is on and you leave the template empty, trying to save the settings brings up a message that a template is required, and the window stays open.

Ignore missing archives
If the archive holding the file on disk cannot be found or is damaged when you try to open a book (for reading or for sending), then by default (checkbox on) MyHomeLib shows no separate message naming the archive — the action for that book is simply not carried out. With the checkbox off, a message about the missing archive appears instead.
Treat selected as checked
Lets certain bulk actions (deleting, sending to a device and copying between collections, in particular) count the merely selected (highlighted) rows of the list as "checked", not just the books with a check mark. On by default; turn it off and you will have to tick the books you want individually before those actions. There is an example of the behavior in Selecting and marking books.
