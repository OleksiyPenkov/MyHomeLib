Collection menu

The Collection menu brings together the management of connected collections, the import and export of books and user data, and the maintenance of the active collection's database.

CommandWhat it does
Create a new collection Ctrl+NStarts the wizard for creating a new collection. See Creating a collection.
Select collectionA submenu listing the other connected collections — picking one makes it the active collection.
Collection propertiesOpens the properties of the active collection. See Collection properties.
StatisticsShows a window with statistics for the active collection.
Update collection from file...Updates the active collection from an INPX book list picked on disk — either partially or with a full reimport. See Updating a collection.

The "Import" submenu

CommandWhat it does
FB2 and fb2.zip filesImports books in FB2 or FB2.ZIP format into the active collection. See Importing FB2 books.
Non-FB2 filesImports books in other formats (PDF, DjVu, EPUB and so on). See Importing non-FB2 and FBD books.
FBD files (pdf.zip djvu.zip)Imports ready-made FBD description files together with the book files.
User dataImports a previously exported user data file (ratings, groups, reading progress). See User data export and import.

The "Export" submenu

CommandWhat it does
Export active list (submenu: html, txt, RTF)Exports the book list currently shown in the window to a file in the chosen format. See Exporting a book list.
Export to INPXExports the whole active collection to a catalog file in INPX format. See Exporting to INPX.
User dataExports the ratings, groups and reading progress of the active collection to a file. See User data export and import.

The "Maintenance" submenu

CommandWhat it does
Update genre listRe-reads the collection's genre list from the genre list file. See Genre lists.
Synchronize filesFor an online collection, reconciles the state of the downloaded files with the server; for a local one, reconciles the contents of the collection's folders and files. See Syncing folders and files.
Check databaseRuns an SQLite integrity check on the collection database and reports either that no errors were found or the list of problems. It changes nothing and repairs nothing. See Database maintenance.
CompactCompacts the collection's database file. See Database maintenance.

Deleting a collection

CommandWhat it does
DeleteDisconnects the active collection from the program, optionally deleting the collection database file as well. See Deleting a collection.
