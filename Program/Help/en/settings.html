Program settings

The settings dialog is opened with the Tools → Settings command (see Tools menu). On the left of the window is a tree of sections, on the right the page of fields belonging to the selected section; moving between sections neither applies nor discards the changes you have already made on the other pages — everything is saved together when you finally press Save. The Cancel button closes the window, discarding all the changes on all the pages at once.
