FAQ

Where are the settings and the system database stored?

By default MyHomeLib keeps its settings and the system database (see Key terms) in the %APPDATA%\MyHomeLib folder, and the database itself in the Data subfolder inside it. If there is a portable-mode marker next to the program's executable (or if there is no Windows user data folder at all), MyHomeLib stores those same files in a folder of its own next to MyHomeLib.exe instead. For details see Portable version.

Why does a book not open?

Usually for one of two reasons. First, no reader may be assigned to the file extension while Windows has no default program for that file type either — in that case assign a reader in File types and readers. Second, the book file itself may have gone from disk — moved, renamed or deleted outside MyHomeLib; this is reported by the error "File … not found! Check the collection settings!".

Why is a downloaded book missing?

A downloaded book goes into the very online collection it was downloaded from, not into some separate "downloads" folder — check that this is the collection you have open. If the download ended in an error, the details are written to the download_errors.log log next to the program settings. See Downloading books.

What happens if the collection file disappears from disk?

MyHomeLib keeps the path to the collection file and its other properties in the system database, not in the collection file itself. So when a .hlc2 file has been moved, renamed or deleted outside the program, the collection does not vanish from the list you switch collections with (Collection → Select collection) — that list is built without checking whether the file exists. You will not be able to open that particular collection, though, until the file is put back where it was or the collection is connected again with the new path; see Working with collections. The message "Collection file not found. The program cannot start." appears only once — at startup, and only when the files of every single registered collection are unavailable at the same time; if even one of them still has its file, MyHomeLib simply opens that one instead of the collection that went missing.

How do I move a collection to another drive?

Copy (or move) the folder holding the book files and the collection database file to the new drive, then open the collection properties and enter the new path in the Books folder: field. See Collection properties.

How do I move my whole library to a new computer?

Copy the MyHomeLib data folder (the system database, the settings, the logs) to the new computer along with the folders that hold the collection files, keeping the same paths; or use portable mode — then all of it already sits next to the program and moves by copying a single folder. See Portable version. To transfer or merge only the user data (ratings, groups and so on) separately, use the tools described in User data export and import.
