Book menu

The Book menu holds the actions on the book (or books) selected in the active list.

CommandWhat it does
ReadOpens the selected book in the program configured for that file type (see File types and readers), or, if nothing is configured for the type, in whatever program Windows treats as the default for it. MyHomeLib has no built-in reader.
Send to deviceCopies the selected books into the configured device folder, converting them to the format the device needs if necessary.
Add to download list Ctrl+LQueues the book (in an online collection) for downloading, on the Download list tab.
Mark as readToggles the reading progress: if it is 0%, it is set to 100% (the book is "read"); in any other case the progress is reset to 0%.
Rating (submenu: *, * *, * * *, * * * *, * * * * *, Clear)Gives the book your personal rating of one to five stars, or removes it with the Clear item.
Add to FavoritesAdds the book to the Favorites group. When the active tab is already showing Favorites, this item is hidden and a separate Remove from group item takes its place (see below).
Add to groupA submenu listing the existing groups (Favorites aside) — picking a group adds the selected book to it.
Remove from groupRemoves the book from the group you are currently browsing (available only while viewing the contents of a group or of Favorites).
Copy to collectionA submenu listing the eligible local FB2 collections — picking a collection copies the book into it.
DeleteDeletes the book from the active collection.
ExitCloses the program.

Careful: Mark as read does more than mark an untouched book as read — for a book with any non-zero progress (including one already at 100%) it resets the progress to 0%. Applying the command a second time to a partly read book loses the reading progress you had.
