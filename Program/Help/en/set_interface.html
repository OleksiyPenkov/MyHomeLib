Interface

The Interface section of the settings dialog (see Program settings) controls the fonts and colors of the trees and the book lists.

Font

List font size
The font size of the central book list and of the tree on the left.
Info panel font size
The font size of the auxiliary panels beside the tree (captions, counters and the like).

Both font sizes take effect only after the program is restarted — the section says as much itself.

List font color

The general color of the text in the central book list; the Change button opens the standard Windows color picker. Two exceptions to this general color are set separately:

Downloaded books
The text color of books of an online collection whose file has already been downloaded to disk.
Deleted in the online library
The text color of books that the source library has marked as deleted (the record stays in the catalog — see Deleting books); whether such books appear in the list at all is toggled by a separate View menu command, not by this setting.

Alternating background in book lists

The background colors with which the book list visually tells rows of different kinds apart — each with a Change button of its own:

Author
The background of an author heading row (when browsing a tree grouped by author).
Series
The background of a series heading row.
Book without a series
The background of the row of a book that belongs to no series.
Book in a series
The background of the row of a book that belongs to a series.

General background is set on its own — the background of the tree of authors, series and genres to the left of the book list.
