Keyboard shortcuts

Below are all the keyboard shortcuts registered in the MyHomeLib main window. The shortcuts in the "Book list" table work whenever the main window is active, whether or not the corresponding context menu is open.

Book list

ShortcutCommand
EnterRead
Ctrl+DSend to device
Ctrl+LAdd to download list
Ctrl+RMark as read
Ctrl+Alt+AGo to author
Ctrl+IBook info
Ctrl+EEdit description
Ctrl+FAdd to Favorites
Ctrl+ACheck all
Ctrl+SSelect all
Ctrl+MCheck selected
Ctrl+UUncheck all
Ctrl+CCopy to clipboard

The author, series and genre trees

ShortcutCommand
Ctrl+CCopy to clipboard

Collections

ShortcutCommand
Ctrl+NCreate a new collection

Tools

ShortcutCommand
F3Quick search

The list covers only those key combinations that are actually declared in the program's main window form. Ctrl+C, for example — familiar as it is from Windows — has two different meanings here depending on which list is active, the book list or the browsing tree.
