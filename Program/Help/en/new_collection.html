Creating a collection

The Collection → Create a new collection command (Ctrl+N) starts a wizard that creates a new empty collection, connects an existing one and builds a collection from an INPX file. Which steps the wizard shows depends on the choice you make on the second step — below they are listed in the order in which they actually follow one another, and steps marked as conditional appear only for a particular choice.

Step 1. Welcome

The opening page of the MyHomeLib Add Collection Wizard — explanatory text only, with no fields to fill in.

Step 2. Collection type

Here you choose what the wizard is going to do:

  • New empty collection — create an empty collection, which you then fill by importing books;
  • Existing collection (HLC2) — connect a collection file that already exists;
  • Collection from an INPX file — create a collection and fill it straight away from an INPX catalog file (see Key terms).

Step 3. INPX source (only for "Collection from an INPX file")

Shown only if you picked Collection from an INPX file on the previous step. Here you say where the INPX file is to come from:

  • Local INPX file — a file already on your disk (the Select button opens a file picker);
  • Download from website — a list of ready-made collections (lib.rus.ec, Flibusta and so on), whose sources are taken from the collections.ini file (see Installation); the INPX file will be downloaded from the server. This option is available only if that list is not empty.

The type of the collection to be (private or external, local or online, FB2 or non-FB2) is settled later, from the data stored inside the INPX file itself; see Collection types.

Step 4. Downloading the INPX file (only if you chose "Download from website")

Shows the progress of downloading the chosen INPX file from the server: the speed and the amount downloaded so far. There is no such step when the INPX file comes from a local disk.

Step 5. Collection name

A step common to every option: the collection name, the collection file and the book folder.

  • Collection name — any name you like, under which the collection will appear in lists and menus; it has to be unique among the connected collections;
  • Collection file — the path to the .hlc2 file. For a new collection and for a collection from INPX you say where the file is to be created (the Select button); for connecting an existing collection, where to find the file that is already there;
  • Books folder — the folder where this collection's book files will be stored (or are stored already).

If the collection is being created from an INPX file, the wizard fills in the name and the collection file from the data stored inside the INPX itself — you can correct that by hand.

Step 6. File format (only for "New empty collection")

Shown only if you picked New empty collection on step 2. It determines what the future collection will hold:

  • Books in FictionBook format — the collection will store FB2/FB2.ZIP books, with the standard FB2 genre tree;
  • Books in other formats (FBD, PDF, DJVU) — a collection for non-FB2 books, with a genre tree of its own (the next step lets you choose the genre file).

The Start importing books after the collection is created checkbox (on by default, available for FB2 only) opens the book import as soon as the collection has been created — see Importing FB2 books.

Step 7. Genre description file (only for a new non-FB2 collection)

Shown only when a new empty collection is being created with the Books in other formats format. For a new FB2 collection, for connecting an existing one and for creating from INPX the genre file is chosen automatically, and this step does not appear.

  • Default — use the genre description file that ships with the program;
  • Custom genre file — point to a file of your own (the Select button).

The Start the import after the collection is created checkbox here repeats the same choice as the one on the file format step. For the genre files themselves see Genre lists.

Step 8. Progress

A step common to every option: here the wizard actually creates or connects the collection in the system database and, for the INPX options, imports the data from the INPX file straight afterwards (with an event log and a progress bar). Only the Cancel button is available on this step — there are no buttons for moving to the previous or the next one; if registering the collection could not be completed, the wizard stays on this page and offers to save the error log.

Step 9. Finish

The closing page: the collection has been created (or connected), and you can start using it as soon as the wizard closes.
