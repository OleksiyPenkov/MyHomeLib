Downloading books

In an online collection the book catalog and the book files themselves lead separate lives: the record of a book appears when the collection is updated, while the file is fetched from the library server only when it is really needed. This section is about the download queue you drive by hand; for the division of collections into local and online, see Collection types.

Adding to the queue

The Add to download list command (Ctrl+L, available both from the Book menu and from the book list context menu — both items are bound to the same action) puts the checked books into the queue on the Download list tab. The item is shown only for books of an online collection; for private (local) books it is absent, because their files are already on disk.

The "Download list" tab

This tab shows the download queue: how many books are in it (the counter in brackets next to the tab name), which book is downloading right now (author and title above the progress bar) and the state of every entry — waiting, downloading or failed. The buttons beside the list move the selected entries through the queue ("Move to top", "Move up", "Move down", "Move to bottom"), and the same toolbar also carries "Delete", "Save" and "Clear". The context menu of the list ("Go to author", "Delete") is described in Context menus.

Start, stop, retries

The Start button sets the queue going: the books are downloaded one after another with a pause between them (configurable — see Internet and proxy); a book that downloads successfully disappears from the list, while a book that fails stays in it marked as failed. The Stop button halts the queue after the current file, without undoing anything already downloaded.

There is no separate "Retry" button: if only failed entries are left after a pass through the queue, pressing Start again takes them up once more from the top of the list. If a genuine error occurs during a download (as opposed to a cancellation by you), the program asks whether to ignore errors of that kind for the rest of the current pass.

The queue is stored on disk between runs of the program — close MyHomeLib with the queue unfinished and you will find the same entries there next time you start it.

Where the files end up

A downloaded file goes into the collection folder at the path already assigned to that catalog record (worked out from the author and title of the book when the collection was updated) — there is no destination folder to pick for each download.

The error log

The program does provide for a download error log file (download_errors.log in the program's working folder), but writing it is governed by a separate option that has no switch in the settings window in the current version, and it is off by default. In practice, then, you learn about download errors from the dialogs shown during the process itself and from the state of the entry in the queue, not from a log file.

A one-off download of a single file, outside the queue, also happens away from this tab: if you open for reading, or send to a device, a book of an online collection that has not been downloaded yet, MyHomeLib fetches that one book first, in a small progress window of its own; see Reading books and Sending books to a device.
