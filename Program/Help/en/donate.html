Supporting development

MyHomeLib is free, open-source software (MIT licence) written by enthusiasts — its authors and its community. The best way to say thank you is to help the project directly:

  • Star the repository on GitHub: https://github.com/OleksiyPenkov/myhomelib/ — it makes the project easier for others to find.
  • Report bugs and suggestions on the issues page: https://github.com/OleksiyPenkov/myhomelib/issues.
  • Propose fixes and new features through a pull request.
  • Help with translation and documentation.

For the people behind the program, see About MyHomeLib.
