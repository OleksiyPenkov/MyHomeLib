Editing book descriptions

The editing commands are gathered in the Edit main menu, and the most-used ones are duplicated in the book list context menu (see Context menus). Everything described below applies to private collections — not to online ones, and not to view-only ones.

The book description

The Book info item in the Edit menu and the Edit description item (Ctrl+E) in the context menu open one and the same description editing window.

The caption "Book info" is misleading here: despite the name, this item opens the editor straight away rather than a read-only view — that is an existing quirk of the program's interface, not a mistake in this help. A separate, view-only command does exist (also called "Book info", Ctrl+I), but it is a different context menu item.

In the editing window you can change the title, the series and the book's number in it, the keywords, the language, the genre (with a button that opens the genre tree) and the book's list of authors (the Add, Change and Delete buttons above the author list — each opens a small window with Last name, First name and Middle name fields). The Open button lets you read the book without closing the editor; the >>> and <<< buttons save the current description and move to the next or the previous book in the active list without closing the window.

Author

The Author item of the Edit menu is available only on the Authors tab, with an author selected in the tree. It opens the same small window with the Last name, First name and Middle name fields, but what it changes is the author record in the collection database rather than a single book — so a rename made there applies at once to every book by that author in the collection, not only to the one you started from.

Older versions of this help described an extended version of this editor, with New author and Save links checkboxes. That form no longer exists in the program, so there is no point looking for a way to open it: editing an author always happens in the small window described above.

Converting to FBD

The same Edit menu offers a Convert to FBD item for a selected book in a non-FB2 format — it opens a conversion window much like the one for adding a file by hand (see Importing non-FB2 and FBD books). The adjacent Convert to FBD automatically item is not handled at all in the current build of the program: clicking it does nothing.

When changes reach the FB2 file itself

Editing a description here changes only the collection catalog (the book, author and genre tables in the database), not the book file on disk. The current catalog data (author, title, genre, series) is written into the FB2 file itself on two separate occasions only — and even then only if the Overwrite the FB2 header option is turned on in the settings:

  • when an FB2 or FB2.ZIP book is sent to a device — what gets rewritten is the copy the device receives, not the file in the collection (see Sending books to a device);
  • when an unpacked FB2 file is opened for reading straight from the collection folder — here it is the file in the collection that gets rewritten (see Reading books).

In both cases the book title that ends up in the file is built from a separate title template in the settings — the same one used for the file name templates on import and export.
