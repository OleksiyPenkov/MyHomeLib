Importing non-FB2 and FBD books

A book that is not in FB2 format (PDF, DjVu, EPUB, TXT and so on) carries no author, title or genre inside it that the program could read on its own — unlike FB2. So that such a book still appears in the catalog like any other (with an author, a title, a series and a genre), a small companion description is created for it — an FBD file: it is packed into a single archive together with the book file itself, and from that moment the book behaves in the collection like an ordinary record. The Collection → Import menu offers two different ways to do this — manual and batch; these are two separate commands with different dialogs, not two modes of one window.

Non-FB2 files — adding books by hand

This command opens a window of its own in which you type the bibliographic data yourself. The window scans the collection folder itself (not a separate import folder) and shows, as a tree, the files whose extension has a reader configured for it (see File types and readers) and which are not in the catalog yet; fb2 and fb2.zip files are left out of that list — they have an import of their own.

For the selected file you fill in, by hand, the author (with a button, or from the list of authors already in the collection), the title, the series with its number, the genre (through the genre tree), the keywords and the language; buttons such as Last name, First name, Title and Series put the highlighted fragment of the file name into the matching field in one click. The Convert to FBD check box turns on the creation of an FBD archive for the file; without it the file goes into the catalog as it is, with no FBD wrapper. The Save button writes the book to the catalog and moves on to the next file in the list.

In this window the field group headings read Options and Cover, and the hints on the cover buttons are translated as well; older builds left several of these captions in Russian, but that is no longer the case.

FBD files (pdf.zip djvu.zip) — batch import

This command is meant for ready-made FBD archives (received from someone else, say, or prepared in advance) — the same .zip files that hold the book file together with an .fbd description file. Unlike Non-FB2 files, nothing here is typed by hand: the command scans the import folder, finds the FBD description in each archive and reads the author, title, genre and series out of it by itself — much as the FB2 import reads that data from an fb2 file. Progress is shown by the same window with a live error list and a button for saving that list to a file as in the FB2 import — there is no separate log file written automatically.

Duplicates

In both cases, a book for which the catalog already holds a record with the same file name in the same folder is not added a second time.
