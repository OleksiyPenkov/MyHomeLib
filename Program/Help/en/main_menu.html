Main menu

The MyHomeLib main menu has seven top-level items. The four largest have detailed pages of their own; the remaining three are described in full below.

Overview

MenuPurpose
BookActions on the book selected in the list: read it, send it to a device, rate it, add it to a group, copy it to another collection, delete it. In detail — Book menu.
CollectionCreating, selecting and configuring collections; importing and exporting books and user data; maintaining the collection database. In detail — Collection menu.
GroupManaging your own book groups (Favorites aside — it can be neither renamed nor deleted). Described below.
EditThe same commands for editing a book, an author, a series and a genre as on the edit toolbar. Described below.
ViewVisibility of the toolbars and the status bar, contents of the book info panel, display mode of the book list, choice of table columns. In detail — View menu.
ToolsQuick search, updating online collections, clearing the "Reading" folder, running scripts, program settings. In detail — Tools menu.
HelpHelp, checking for updates, the program website, the About window. Described below.

The Group menu

CommandWhat it does
Create groupCreates a new named book group.
Rename groupRenames the group selected on the Groups tab.
Clear groupRemoves every book from the selected group without deleting the group itself.
Delete groupDeletes the selected group along with its list of books (the books themselves stay in the collection).

The built-in Favorites and To read groups are not governed by these commands — they can be neither renamed nor deleted.

The Edit menu

CommandWhat it does
Book infoOpens the full description of the selected book for editing.
Convert to FBDConverts the description of a non-FB2 book into an FBD file.
Convert to FBD automaticallyHas no handler in the current build — choosing this item does nothing.
AuthorOpens the author details of the selected book for editing.
Series nameOpens the series name for editing.
Genre nameOpens the genre name (alias) for editing.

The Help menu

CommandWhat it does
HelpOpens this help file.
Check for updatesContacts the project site and reports whether a newer version of the program is available.
Program websiteOpens the project page in your browser.
AboutShows a window with the program's version details. See About MyHomeLib.
