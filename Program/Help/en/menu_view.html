View menu

The View menu controls which panels the window shows, how the books are displayed in the list and what the book info panel contains. Most of the items are toggles: choosing one a second time switches off what the first choice switched on.

The Toolbars submenu

Despite its name, this submenu also governs the two alphabet strips, not just the toolbars proper.

CommandWhat it does
Main toolbarShows or hides the main toolbar.
Edit toolbarShows or hides the edit toolbar (the Author, Series name and similar buttons).
Cyrillic alphabetShows or hides the row of Cyrillic letters above the tree on the Authors and Series tabs.
Latin alphabetThe same for the Latin alphabet.
CommandWhat it does
Status barShows or hides the status bar at the bottom of the window.
Book info panelShows or hides the right-hand panel with the cover, annotation and description of the selected book.

The Additional submenu

CommandWhat it does
Show coverShows or hides the book cover on the book info panel.
Show annotationShows or hides the annotation text on the book info panel.
Show BookInfoSwitches what the book info panel contains: instead of the annotation it shows the technical details of the book file (folder, file name and so on).

The View mode submenu

CommandWhat it does
As a treeShows the active book list as a tree grouped by author or by series.
As a tableShows the active book list as a flat table with no grouping.

Other commands

CommandWhat it does
Select table columns...Opens the dialog for choosing and ordering the columns of the book table.
Hide deleted booksHides the books marked as deleted from the list.
Show downloaded books onlyLeaves only the books whose files have already been downloaded to disk in the list.

You can also pick the columns of the book table by right-clicking the table header — see Context menus.
