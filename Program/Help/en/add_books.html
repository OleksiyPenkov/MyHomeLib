Adding books to a collection

Books reach a collection in three different ways. Which one you use depends on what sort of collection it is and where the files come from.

MethodWhen to use it
Importing FB2/FB2.ZIPYou already have FB2 (or fb2.zip) files on disk and need records for them in a private (local) collection. The program scans the folder you point it at, reads the author, title, genre and so on out of every file, and copies the files into the collection folder.
Importing non-FB2 and FBDThe book is not in FB2 (PDF, DjVu, EPUB, TXT…) and its bibliographic data has to be typed in by hand — or someone has already prepared such a description as an FBD file.
Downloading from an online collectionThe collection is online: the catalog already holds the book's description, and the file itself is fetched from the library server only when it is really needed — when you read it, send it to a device or download it explicitly.

There is a fourth way, which is not "adding" in the strict sense: the Book → Copy to collection command moves the record of a book you already have from one private FB2 collection into another without importing the file again; see Copying books between collections.

Synchronizing the folder

If the book files in the collection folder change outside the program (added, renamed or deleted by you or by another application), you can bring the catalog back in line with the folder using Collection → Maintenance → Synchronize files — this is not an import of new books from an arbitrary place but a reconciliation of the collection folder already attached to the collection with the state of the disk; see Syncing folders and files.

Every method of importing and synchronizing is available for private (local) collections only. An online collection is filled by updating its catalog from the library server (see Updating a collection) and then downloading the files themselves.
