Genre lists

The genre tree that books are arranged by on the browsing tab (see Browsing: authors, series, genres), and that is offered to you when you edit a book description, does not come from the collection itself but from a separate genre list file.

Two lists: FB2 and non-FB2

The program ships with two ready-made genre lists, installed next to the executable (see Installation):

  • genres_fb2.glst — the standard FictionBook genre tree, for FB2 collections;
  • genres_nonfb2.glst — a separate tree for collections of arbitrary formats (non-FB2).

Which of them a new collection gets — and whether you may replace it with one of your own — is decided while the collection is being created, on the wizard's Genre description file step (see Creating a collection): an FB2 collection always gets the standard FB2 genre file, while a collection of arbitrary formats can either keep the standard non-FB2 file or use a file of your own with the .glst extension. Translated copies of both standard lists are installed alongside them, and the program prefers the copy matching the interface language whenever one is present.

Updating a collection's genre list

The Collection → Maintenance → Update genre list command re-reads the genre file for the active collection. For an FB2 collection that is always the standard genres_fb2.glst file, with nothing to ask about. For a collection of arbitrary formats the command opens a file selection dialog every time — you can point it at the same file again or at a different one.

The update replaces the collection's list of available genres wholesale with the list from the file. If a genre code that had already been assigned to books is missing from the new file, that genre marking is lost from those books — the book itself does not disappear from the collection, but the genre that is no longer in the file is stripped from it.
