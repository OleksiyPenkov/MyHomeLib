Collection properties

The Collection → Collection properties command opens the Collection properties window with the fields of the active collection. The window warns you: Warning! Changing the collection properties incorrectly can make the collection unusable! — and that is worth taking seriously, not least because the books folder and the collection file are changed here without any check of the files actually on disk.

The General tab

FieldWhat it means
Collection nameThe name under which the collection appears in lists and menus. Editable; it has to stay unique among the connected collections.
Collection fileThe path to the .hlc2 database file. Read-only — the field shows where the collection's registration points, but the window will not let you change it.
Books folderThe folder holding the collection's book files. Editable (the Select button); changing it only moves the pointer — no book files are moved anywhere.
Collection descriptionA free-form text description, shown by the Statistics window (see Working with collections). Editable.

The Connection tab (online collections only)

This tab appears only when the active collection is an online one (see Collection types); for a local collection it is not shown at all.

FieldWhat it means
URLThe address of the library server. Editable.
User / PasswordThe credentials for logging in to the library server. Editable.
Connection scriptThe text of the script MyHomeLib uses to log in to this online collection and to search and download books from it. This is a property of the collection itself — not to be confused with the scripts that run after books are sent to a device, which are configured separately. Editable.

What cannot be changed

Besides the collection file, this window has no field for the collection type (see Collection types) or for the file format (FB2 or non-FB2) — both are fixed for good when the wizard creates the collection, and nothing in the program edits them afterwards.

Saving

The Save button checks that the collection name and file are filled in, that neither is already registered to another collection, and that the collection file given exists on disk — and only then writes the new property values.
