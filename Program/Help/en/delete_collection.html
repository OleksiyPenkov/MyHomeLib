Deleting a collection

The Collection → Delete command always applies to the active collection — you do not need to select it first. The command opens a dialog with two options, and it is that choice which decides how serious the consequences are.

Two options — and the difference between them is fundamental

Disconnect collection
Removes the collection from the list of connected collections and nothing more. The .hlc2 collection file and the book files stay on disk unchanged. You can connect this collection again with the Create a new collection command: on the Collection type step pick Existing collection (HLC2) and point it at the same file.
Delete collection
Removes the collection from the list of connected collections and additionally deletes the .hlc2 collection file itself from disk. Deleting that file is irreversible — without a backup copy of it, the catalog of books, authors, series, groups and other data belonging to this collection cannot be recovered.

What is never deleted, whichever option you pick

The book files in the collection folder are never deleted, whichever option you pick — only the .hlc2 catalog file is removed. To free the space the books take up, you have to delete their folder by hand, in Windows Explorer, outside MyHomeLib.

What this means for the rest of the program

After a deletion or a disconnect, the first of the remaining connected collections becomes the active one; if none are left, there is no active collection at all until you connect or create one — see Working with collections.
