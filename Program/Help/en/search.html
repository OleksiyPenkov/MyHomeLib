Search and filters

The Search tab is a book list of its own, filled not by browsing the author, series or genre tree but by an arbitrary set of conditions. Unlike the browsing trees, it can search several fields at once and can store a set of conditions for reuse.

Search fields

The panel on the left is made up of three collapsible groups.

Book
Author, Title, Series, Genre (with a button that opens the genre tree so you can pick with the mouse), Keywords, Annotation.
File
Name, Folder (archive), Type — that is, the file extension.
Misc
Date added (ready-made intervals in a drop-down list — Today, Last 3 days, Last week, Last 2 weeks, Last month, Last 3 months), Lang (a two-letter code), the external library Rating (1–5), and the Hide deleted and Read books only checkboxes.

Simple and advanced search

The simplest approach is to type text into the field you want: MyHomeLib looks for it as a case-insensitive substring anywhere in the value. For a more precise query, the same field also understands a direct, SQL-like condition syntax:

  • %text% — an explicit substring, with the option of putting % on one side only;
  • ="exact value" — an exact match;
  • <, >, <> — comparisons (handy for a date or a size);
  • ="name1" OR ="name2" — several alternatives in one field; this is exactly the form in which several authors selected at once through the Add to "Search" item of the author tree are placed into the Author field (see Context menus).

The button to the right of each field opens a separate editing window for it — more comfortable for a long or multi-line query than a single-line field. In the Genre field the same button opens the genre tree instead of a text editor: what you select there is placed into the field as a list of genre aliases rather than as free text.

Pressing Enter in any field starts the search straight away, just as the Apply button does.

Search scope

The search covers only the collection that is active at that moment. To find a book in another connected collection, switch to it first (see Working with collections) and then repeat the search.

Presets

A filled-in set of conditions can be stored under a name of your choosing with the Save button and recalled later by picking that name from the list above the search panel. The Delete button removes the selected preset from the list (its tooltip reads Delete preset). The Clear button empties every field without touching the preset selection. Presets are stored in a separate file in the program's working folder and are shared by all collections.
