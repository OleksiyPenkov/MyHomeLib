Reading books

MyHomeLib never displays the contents of a book itself — it only catalogs the files and, on the Read command, hands the file over to an external program. MyHomeLib has no built-in reader.

How the program is chosen

By the file extension, the program looks up the reader assigned to it in the File types and readers list. If a reader is configured for the extension, that is the one that starts; if not, the file is opened by whatever program Windows itself has associated with that extension (the ordinary file association).

The installer places the AlReader reader next to the program and, on the first run, while the reader list is still empty, adds it as the default for the fb2, doc, txt, htm and html extensions — no default reader is assigned for PDF, DjVu and some other types, so for those the Windows association is used straight away. Even AlReader, though, is nothing special as far as MyHomeLib is concerned: it is started as a separate program and given the path to the file, exactly like any other reader.

What happens when a book is opened

If the book is stored in an archive (fb2.zip, FBD, packed non-FB2), MyHomeLib first extracts the file it needs into the Reading working folder under the name "Author - Title" (shortening it where necessary) and opens that copy in the reader; if a file of that name is already there from last time, it is not extracted again. Unpacked FB2 and raw files are opened directly from the collection folder, without being copied. The contents of this working folder can be cleared in one go with the Tools → Clear the "Reading" folder command.

If the book belongs to an online collection and has not been downloaded yet, MyHomeLib fetches that one book first (a brief intermediate progress window); if the download fails, the book is not opened.

If the Overwrite the FB2 header option is switched on in the settings, opening an unpacked FB2 file of a private collection for reading immediately rewrites the author, title, genre and series inside that very file with the values from the catalog — this happens to the file sitting in the collection folder, not to a temporary copy. The same option and the same code govern the rewriting of the header when books are sent to a device; see Editing book descriptions and Sending books to a device.

If nothing opens

  • Check in File types and readers that the path recorded for the extension still exists on disk (move or update a reader and the path may have gone stale).
  • For a book of an online collection, make sure the file really has been downloaded (the book list shows a marker for books held locally) — if a download has just failed, try again through the download queue.
  • If no reader is assigned to the extension, the ordinary Windows association takes over — make sure the system has anything at all to open that file type with.
