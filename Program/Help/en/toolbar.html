Toolbar

MyHomeLib has two toolbars — the main one and the edit toolbar. Both can be hidden or shown from the View menu → Toolbars.

The main toolbar

ButtonWhat it doesMenu equivalent
ReadOpens the selected book for reading.Book → Read (Enter)
Add to download listQueues the selected (checked) books for downloading from an online collection.Book → Add to download list (Ctrl+L)
The button hinted "Send to device"Copies the selected books to a device using the default script; the arrow drops down the list of configured scripts so you can pick another.Book → Send to device
Cyrillic alphabetShows or hides the strip of Cyrillic letters above the tree on the Authors and Series tabs.View → Toolbars → Cyrillic alphabet
Latin alphabetThe same for the Latin alphabet.View → Toolbars → Latin alphabet
The button hinted "Select collection"Drops down the list of connected collections for switching between them, plus an item for creating a new collection.Collection → Select collection / Create a new collection
Add to FavoritesAdds the selected books to the Favorites group; the arrow drops down the list of the other groups to choose from.Book → Add to Favorites (Ctrl+F in the book list)
The button hinted "Check all"Turns the check marks in every row of the active book list on or off.Book list context menu → Check all / Uncheck all
The button hinted "Expand/Collapse list"Fully expands or collapses the active tree of books.—
The button whose hint reads Switch to "Table" modeSwitches the active book list between tree mode (with grouping) and a flat table.View → View mode
Hide deleted booksHides the books marked as deleted from the list.View → Hide deleted books
Show downloaded books onlyLeaves in the list only the books whose files are already on disk.View → Show downloaded books only
Book info panelShows or hides the right-hand panel with the cover, the annotation and the book description.View → Book info panel
SettingsOpens the program settings window.Tools → Settings
The button hinted "Help"Opens this help.Help → Help

The edit toolbar

This toolbar shows text buttons for editing the book selected in the list.

ButtonWhat it doesMenu equivalent
AuthorOpens the author details of the selected book for editing.Edit → Author
Series nameOpens the series title for editing.Edit → Series name
Genre nameOpens the genre name (alias) for editing.Edit → Genre name
Book infoOpens the full book description for editing.Edit → Book info
DeleteDeletes the selected book.Book → Delete
Convert to FBDConverts the description of a non-FB2 book into an FBD file.Edit → Convert to FBD
Convert to FBD automaticallyIn the current build the button is not wired to anything — clicking it does nothing.Edit → Convert to FBD automatically
