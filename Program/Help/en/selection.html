Selecting and marking books

There are two independent ways of marking rows in the book list, and the commands that act "on several books at once" do not react to both in the same way.

Selection
The ordinary highlighting of rows with the mouse or the keyboard (with Shift, Ctrl and so on) — exactly as in any Windows list. On its own it is not a "set of books to act on", it merely shows which row is active.
Check mark
The check box to the left of the row. It is the checked rows (not necessarily the selected ones) that most multi-book commands treat as the set chosen for the action.

Which commands react to what

The commands of the Book menu and of the list context menu that apply to several books at once (Mark as read, the Rating submenu, Add to Favorites, Add to group and others) act on the checked rows; if nothing is checked, the action applies only to the single current (active) row.

The Delete command is the exception: whether merely selected rows count as checked for it is decided by the Treat selected as checked option in the settings (Behavior), which is on by default. So normally it is enough to select a few rows with the mouse and press Delete, without checking them separately; turn the option off and you will have to check the books first in order to delete several of them.

Commands for managing selection and check marks

CommandShortcutWhat it does
Check allCtrl+ATurns the check box on in every row of the list, leaving the selection alone.
Select allCtrl+SSelects (highlights) every row of the list, leaving the check boxes alone.
Check selectedCtrl+MTurns the check box on only in the rows that are selected at that moment.
Uncheck allCtrl+UTurns the check box off in every row of the list, leaving the selection alone.

All four commands are available in the context menu of the book list; the full list of that menu's items is in Context menus.
