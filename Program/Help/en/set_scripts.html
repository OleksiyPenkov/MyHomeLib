Scripts

A script here is not a script for logging in to an online library but an external program (or batch file) that MyHomeLib launches immediately after books have been sent to a device, with parameters ready to be substituted. It is a way of adding "destinations" or actions of your own to the ordinary Send to device command (see Sending books to a device) — so that the same click also starts a device sync program, copies the files to a second place as well, or simply opens the result folder.

The list of scripts

The Scripts section of the settings dialog (see Program settings) has a table with the columns Title, Path and Options, and three buttons below it:

Add / Change
Opens the Script parameters window with the fields Title:, Path: (the Browse... button offers .exe, .bat, .cmd, .vbs and .js files, though you can type the path by hand) and Parameters:. Title and path are required; without either of them the entry cannot be saved.
Delete
Removes the selected script from the list.

The Default: drop-down list says which of the scripts (or "Standard", meaning none at all) runs when you press the Send to device button on the toolbar itself without opening its list; for more about that button see Toolbar.

When scripts run

There are three equivalent ways to run the script you want:

  • the arrow beside the Send to device button on the toolbar — it drops down the list of every configured script;
  • the Run script submenu of the Tools menu (see Tools menu);
  • the Run script item in the context menu of the book list (see Context menus).

In all three cases MyHomeLib first performs an ordinary send of the checked books — copying and, if needed, converting them into the folder and format, and under the name templates, configured in Devices and export — and only then launches the program from the Path column with the parameters from the Options column substituted.

Substitutions in the parameters

The Parameters field accepts the following markers (they are substituted only into the parameter string handed to the program; the file on disk is not changed):

MarkerWhat is substituted
%DEST%The folder the books have just been sent to.
%TMP%MyHomeLib's temporary folder.
%FILENAME%The name (or names) of the files just sent.
%FOLDER path%Sets the destination folder straight from the parameters — everything between "%FOLDER " and the next "%" is read as a path and used instead of the folder from Devices and export, and is removed from the parameter string passed to the program.
%NFT%Disables the subfolder template (see Devices and export) for this one run — the files go into the destination folder without a subfolder being built from the template.

The special "%COPY%" path

If the Path field contains literally %COPY%, MyHomeLib launches no external program at all — instead it simply copies the sent files into the folder given in the Options field. The markers %TMP%, %DEST%, %FOLDER path% and %NFT% from the table above are substituted into that string just as they are for an ordinary script — if you do not need them there, an ordinary folder path is all the field takes. This is a handy way to add another copy destination as a single list entry without writing a program for it; for an example see Script examples.
