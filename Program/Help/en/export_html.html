Exporting a book list

The Collection → Export → Export active list command saves the book list currently shown in the window to a file — whatever it is showing: authors, series, genres, search results or the contents of a group; for where the menu item sits, see Collection menu.

Formats

The submenu offers three formats: html, txt (tab-separated) and RTF. All three export the same content — only the file format differs. MyHomeLib opens the finished file straight away in whichever program the system associates with that file type.

What goes into the file

The whole list is exported (every row of the active tab), not just the checked or selected rows, and with exactly the set of columns currently enabled in the list header. The command has no template or content settings of its own: to change the set of fields in the export, first turn the columns you want on or off through the context menu of the list header — see Context menus.

The file is always saved under the same name (book_list with the extension of the chosen format) in the program's temporary working folder — a new export in the same format replaces the previous one. If you need to keep the result, copy or rename the file that was opened.
