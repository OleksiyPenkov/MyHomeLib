Program interface

MyHomeLib is a single-window program: everything you work with (browsing the collection, the book list, book information, downloads) lives in one main window divided into several panels. This page is a short orientation; each part is described in more detail on a page of its own.

What the window is made of

  • The toolbar at the top — buttons for the most frequent actions. See Toolbar.
  • The main menu above the edit bar — access to every command in the program. See Main menu.
  • On the left — the Authors, Series and Genres tabs with a tree for browsing the collection, plus the Search, Groups and Download list tabs. See Browsing: authors, series, genres.
  • To the right of the tree — the list of books for the selected author, series or genre.
  • To the right of the book list (optional) — a panel with the cover, the annotation and technical details of the selected book.
  • At the bottom — the status bar, showing a message about the current action and the program version number.

A general description of all these parts and of how they relate to one another is in Main window.

Getting things done quickly

Most actions are available in three ways: a toolbar button, a menu item and a keyboard shortcut. The full list of shortcuts is in Keyboard shortcuts; right-clicking the tree, the book list or the download list opens a context menu with exactly the actions that make sense there — see Context menus.
