Copying books between collections

The Book → Copy to collection command (see Book menu) adds the checked books to the destination collection you pick, without moving them out of the current one or deleting them there.

Choosing the destination collection

The Copy to collection submenu does not list every connected collection, only those that can be copied into at all: private FB2 collections other than the active one. Copying is possible only if the active collection is itself FB2; you cannot copy out of a non-FB2 collection, and external (INPX-based) or online collections cannot be destinations, so if there is no suitable collection the submenu is disabled. Copying is not available from the Groups tab.

What exactly gets copied

For each checked book a new catalog record is created in the destination collection with the same bibliographic data: title, author(s), genres, series and number in it, size, date, along with the rating, reading progress, review and annotation stored for the book.

The book file itself is not copied anywhere — the new record merely points at the same folder and file name as the source does. If the destination collection's book folder holds no file at that path, the book appears in the catalog but cannot be opened or sent to a device until the file gets there by other means (through a separate import, for example).

What does not get copied

The book's membership of groups — including Favorites and To read — is not carried over: in the destination collection the book gets a new identifier, and no existing group points at it. If you want the book in a group in the new collection as well, add it to the group there separately; see Groups and favorites.
