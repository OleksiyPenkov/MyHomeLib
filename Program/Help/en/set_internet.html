Internet and proxy

These two sections of the settings dialog (see Program settings) are described together because both concern network access: Internet holds the connection and update options, Proxy the proxy server those connections go through.

Internet: update options

Updates folder
The folder library update files are downloaded into before they are applied. Leave it empty or point it at a folder that does not exist and the program's working folder is used.
INPX server
The address MyHomeLib takes INPX catalogs from when creating or updating online collections (see Creating a collection and Updating a collection); it is also the fallback for downloading a book or a review when the connected collection has no source address of its own.
Update server
The address MyHomeLib checks for a new version of the program itself.

The three check boxes below govern the automatic checks made while the program runs:

Check for library updates
Check periodically whether updates are available for the connected online collections (on by default).
Run library updates automatically
When a library update is found, start downloading it at once without asking; with the box cleared (the default) the program asks for confirmation first. It is meaningless without the previous box.
Check for program updates
Check periodically for a new version of MyHomeLib and report it (on by default).

Internet: connection options

Connection timeout (ms)
How long to wait for a connection to the server to be established before treating the attempt as failed.
Read timeout (ms)
How long to wait for the server's reply once the connection has been established.
Interval (ms)
The pause between individual files in the download queue (see Downloading books), so that the library server is not hit with request after request. 0 by default (no pauses).

Both timeouts apply to every network request MyHomeLib makes — downloading books and reviews, and checking for updates.

Proxy: the main one

With the Use Internet Explorer settings box ticked (the default), MyHomeLib picks the proxy server up from the Windows/Internet Explorer system settings automatically; if the system reports that no proxy is configured, the connection goes direct, with no proxy. The fields below it (Server:, Port:, User:, Password:) for configuring the proxy by hand are available only when the box is cleared.

This block (automatic or manual) is used for all of MyHomeLib's network traffic apart from what is described separately below for library updates.

Proxy: type

The Proxy type drop-down list offers HTTP, SOCKS 4 and SOCKS 5. This is a shared setting: the same type applies both to the main proxy above and to the separate update proxy below — there is no separate type for the update proxy.

Proxy for collection updates

This block is headed Proxy settings for collection updates; its fields are easy to mistake for the main proxy fields above, so check which heading you are working under before editing them.

This is a separate, entirely independent proxy server, used only when checking for and downloading updates for online collections (and their accompanying INPX files), not for downloading the books or reviews themselves, which always go through the main proxy above. The Do not use a proxy for updates / Use a proxy for updates switch decides whether this traffic uses the separate Server:, Port:, User: and Password: below (the fields are available only with the second option chosen) or connects directly, with no proxy (the default choice). The Internet Explorer settings have no effect on this block.
