Main window

The MyHomeLib main window is divided vertically into several panels. From left to right: the tabs with the browsing tree, the book list and (optionally) the book information panel; above all of them the toolbar and the menu, below all of them the status bar.

Mode tabs

The left part of the window is a set of tabs, each switching the program into a different working mode:

  • Authors, Series, Genres — a tree for browsing the collection along one of these axes; described in detail in Browsing: authors, series, genres.
  • Search — a form with filter fields (author, title, genre, series, date and so on) and saved search presets.
  • Groups — arbitrary groups of books, including the built-in Favorites and To read groups.
  • Download list — the queue of books put in line for downloading from an online collection.

You switch between the tabs by clicking a tab header.

The browsing tree

On the Authors, Series and Genres tabs, the left panel shows a tree of the corresponding objects in the collection: the list of authors, the list of series or the genre tree. Above the tree is a box for searching by node name. The node you select in the tree determines which books are shown in the book list on the right.

The book list

The central panel shows the books matching the selection in the tree (or the search results, or the contents of a group — depending on the active tab); above the list are the name of the selected node, the language filter and a book counter. The list can be shown as a tree grouped by author or by series, or as a flat table — the switch and the list of columns are described in Toolbar and View menu. In the status column of each row, a small icon shows whether the book file is on disk, whether the book has been read and whether it has a review; in the "My rating" column the book's rating is shown as stars.

The book information panel

The right panel (turned on and off with a button or a menu item — see View menu) shows details of the book selected in the list: the cover, the annotation or the technical description of the file (switched with the Show BookInfo option), the author, the series and the genres, with links for jumping straight to them.

The status bar

The status bar sits at the bottom of the window. On its left side the program shows a message about the current action (applying a filter or checking for updates, for instance) and, where appropriate, a progress indicator for a long operation. The right side of the status bar always shows the program version number.
