Installation

System requirements

MyHomeLib is a Windows application, available as a 32-bit (x86) and a 64-bit (x64) build; choose the installer that matches the architecture of your copy of Windows. The installer itself runs with administrator rights. Everything the program needs in order to work — the SQLite library (sqlite3.dll), the bundled AlReader reader and the genre lists — is placed next to the program by the installer, so there is nothing to install separately.

x86 or x64

There are two distributions: Setup_MyHomeLib_<version>.exe (32-bit) and Setup_MyHomeLib_<version>_x64.exe (64-bit). The x64 version installs on 64-bit Windows only; the x86 version runs on both 32-bit and 64-bit Windows. In every other respect the two installers are identical — the same default installation folder, the same shortcuts, the same choice of setup wizard language (English, Ukrainian or Bulgarian).

What the installer writes to the program folder, and what to %APPDATA%\MyHomeLib

By default the program is installed into the standard Program Files folder — Program Files\MyHomeLib for the x64 version, or Program Files (x86)\MyHomeLib for the x86 version on 64-bit Windows. There the installer puts the executable MyHomeLib.exe, the sqlite3.dll library, the bundled AlReader reader, the format converters (where a particular build includes them), the genre lists, the help file, the license text and a shortcut to the project website.

Separately, the installer creates the %APPDATA%\MyHomeLib folder (writable by any Windows user) and puts a single file there — collections.ini, the list of sources for updating online libraries — and only when no such file is there yet. Everything else in that folder — the settings, the system database (Data\user.dbs2, see Key terms) and the working logs — is created by the program itself on its first and later runs, not by the installer; there is more about this in FAQ.

Start menu shortcuts

The installer creates a program group with a shortcut that starts MyHomeLib, a shortcut that opens the help file (the installer writes its caption, MyHomeLib Help, in Ukrainian whichever wizard language you choose), a MyHomeLib website link to the project home page, and an entry that uninstalls the program. Tick the corresponding checkbox during installation and a desktop shortcut is created as well. The setup wizard also lets you skip creating a Start menu folder altogether.

Uninstalling

You can remove MyHomeLib either through the uninstall shortcut in the Start menu program group or through the standard Windows list of installed programs — both run the same uninstaller.

The uninstaller removes not only the files in the program folder but the whole %APPDATA%\MyHomeLib folder as well, including the Data subfolder that holds the system database user.dbs2. Uninstalling the program therefore destroys the list of connected collections, the groups (Favorites among them), and the ratings and notes attached to books. If you want to keep that data, copy the %APPDATA%\MyHomeLib folder somewhere else before you uninstall.

The collections themselves — the book files and the .hlc2 database file — are touched by neither the installer nor the uninstaller: they stay where you put them when you created or connected the collection (see Collection properties), so uninstalling the program does not affect them.
