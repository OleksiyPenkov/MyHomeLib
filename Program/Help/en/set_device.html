Devices and export

The Folders/Devices section of the settings dialog (see Program settings) prepares everything the Send to device command later relies on — the destination folder itself, the conversion format and the name templates; for more about the sending process see Sending books to a device.

The folder on the device

The Folder on the device field (with the Select button beside it) sets the default destination folder. The Ask for the path every time checkbox disables the field and the button and, instead of using the stored folder, opens a folder picker before every send (the choices there can include MTP devices — a phone or a reader connected as a portable device).

Device output format

The Device output format drop-down list sets the conversion format used by the ordinary Send to device command: .fb2, .fb2.zip, .lrf, .txt, .epub, .pdf or .mobi (.fb2 by default). This is only the default format: the program also has separate menu items and buttons for sending in one specific format, which override this choice for that one send — see Book menu and Toolbar.

Name format

Two fields — Folder: and File: — hold the templates that build the subfolder inside the device folder and the file name respectively; the fields only display the current template (they are not meant to be edited in place), and the Change buttons beside them open the template editor. The default values (right after installation) are %fc\%s for the folder, that is "Author\Series" (note %fc, not the book's first author — see the %fc substitution below), and [%n - ]%t for the file (the number followed by a "-" separator before the title, but only if the book has a number in its series; otherwise the title alone).

The template editor

The same editor ("Build template") also opens for the file sorting templates (File sorting) and for the book title template (Behavior). It has two tabs:

  • Template rules — the template field itself plus a reference list of the substitutions;
  • Template test — test fields (last name and first name of two imaginary authors, title, series, number, book ID, two imaginary genres, root genre) with checkboxes; whichever test field is checked is what gets substituted into the result shown right below the template field, so you can check a template without sending a single real book.

The Save button applies the template only if it is syntactically correct (valid substitutions, balanced brackets); if it is not, an error message appears and the window stays open.

Template substitutions

A substitution is a percent sign in front of the element name, with no closing sign (%f, not %f%). The full list is 14 substitutions:

SubstitutionWhat it substitutes
%fThe last, first and middle name of the book's first author.
%fcThe full name of the "current" author — the one whose card is selected in the author tree when the action is started. If the action was not started from browsing by author (from the series or genre tab, say), this substitutes the same thing as %f.
%faThe last name and initials (instead of first and middle name) of all the book's authors, separated by commas.
%flThe first author's last name only.
%fnThe first author's last and first name (no middle name).
%ffThe first letter of the first author's last name.
%sThe series name.
%nThe book's number in the series, padded to at least two digits (01, 02, …); empty if the book has no number.
%tThe book title.
%gThe first genre in the book's genre list.
%gaAll of the book's genres, separated by commas.
%rgThe root genre — the top level of the standard genre tree that the book's first genre (the same one %g gives) belongs to.
%grThe name of the group from whose tab the action was started (for example, "Favorites" while browsing through the Favorites tab); empty outside group browsing.
%idThe book's stable identifier (LibID) — the same one books are matched by when a collection is updated or user data is imported.

Substitution names are read greedily: after the percent sign the program takes every following letter in turn until it has the name of a known substitution. Because of this, a %g immediately followed by the letter "r" with no separator will always be read as the single substitution %gr, never as %g plus a stray letter. If you need literal letters right after a substitution, separate them with something that is not a letter — a space, a hyphen, an underscore and so on.

Writing a substitution name in capitals (%T instead of %t, for instance) substitutes the transliterated (Latin) value instead of the ordinary one — handy for devices or file systems that do not get along with Cyrillic in file names.

Grouping with square brackets

A fragment of a template can be enclosed in square brackets — but each bracket level allows exactly one substitution, no more (trying to put two substitutions in a row inside one pair of brackets makes the template invalid). If that substitution's value is empty, the whole bracketed fragment (along with any text and any nested brackets inside it) is dropped from the result; if the value is there, the brackets themselves are dropped and their contents stay. Brackets can be nested: each nesting level depends only on "its own" substitution, not on the substitutions in the nested level.

An example from the template editor itself — [%s [(%n) ]- ]%t: if the book has no series, only the title remains (%t); if there is a series but no number — "Series - Title"; if there is both a series and a number — "Series (Number) - Title".

Other settings

TXT encoding
UTF-8 or Windows-1251 — the encoding the text is saved in when the device output format is .txt.
Enable the "[...]" filter
When this is on, the first square-bracketed fragment, brackets included, is cut out of the file name that was built (it was designed for the book titles of online libraries such as lib.rus.ec, where service markers in brackets sometimes end up in the title). On by default.

The "Reading" folder

The "Reading" folder field (with a Select button) sets the working folder MyHomeLib unpacks books into from packed sources (FB2.ZIP, FBD, packed non-FB2) before opening them in a reader; see Reading books. If you leave the field empty or point it at a folder that does not exist, the program's temporary folder is used.
