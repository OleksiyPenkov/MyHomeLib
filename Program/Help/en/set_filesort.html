File sorting

The File sorting section of the settings dialog (see Program settings) decides where the import takes files from and whether it lays them out in subfolders inside the collection; the import process itself is described in Importing FB2 books and Importing non-FB2 and FBD books.

Turning it on, and the import folder

The Enable sorting during import checkbox (off by default) switches where the import commands take files from:

  • off (the default) — the import scans the collection folder itself: the files have to be put there beforehand, and during the import they are neither copied nor renamed;
  • on — the import scans a separate folder given in the Folder: field (the Select button), and copies the files it finds into the collection folder, laying them out in subfolders and renaming them according to the templates below.

The rest of the fields in this section are available only while sorting is on.

The "FB2 sorting" and "FBD sorting" templates

Each of the two file types has its own pair of templates, edited with the Change buttons:

Folder
The template for the subfolder inside the collection that the file is copied into.
File
The template for the new file name; if the result is empty, the file name is left unchanged.

Both fields are empty by default — until a template is set, files are copied into the root of the collection under the names they already have. The substitution syntax, the template editor with its test mode and the square bracket rules are the same as for the device templates; the full list of substitutions is in Devices and export.
