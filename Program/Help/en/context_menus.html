Context menus

Right-clicking the browsing tree, the book list or the download list opens a context menu with the actions that make sense in that particular place.

Book list

This menu is the same on every tab that shows a book list (Authors, Series, Genres, Search, Groups).

CommandWhat it does
Read EnterOpens the selected book for reading.
Send to device Ctrl+DSends the book to a device or to a reader program.
Add to download listQueues the book for downloading.
Run scriptA submenu of the scripts configured in the program — it does the same thing as the Run script item on the Tools menu.
Mark as read Ctrl+RToggles the reading progress: if it is 0%, it is set to 100%; in any other case (including a book already read in full) the progress is reset to 0%.
Go to author Ctrl+Alt+ASwitches to the Authors tab and selects the author of this book (switching the active collection first if necessary).
Book info Ctrl+IShows detailed information about the book.
Edit description Ctrl+EOpens the book description for editing.
Add to Favorites Ctrl+FAdds the book to the Favorites group.
Add to groupA submenu listing the existing groups (Favorites aside) to add the book to.
Remove from groupRemoves the book from the current group (the item is shown only while you are viewing a group or Favorites).
Rating (submenu: * … * * * * *, Clear)Sets or removes your personal rating of the book.
Check all Ctrl+ATicks the check box in every row of the list.
Select all Ctrl+SSelects (highlights) every row of the list without touching the check boxes.
Check selected Ctrl+MTicks the check box only in the rows that are selected at the moment.
Uncheck all Ctrl+UClears the check box in every row of the list.
Copy to clipboard Ctrl+CCopies a text description of the selected books to the clipboard.

Careful: Mark as read does more than mark an untouched book as read — for a book with any non-zero progress (including one already at 100%) it resets the progress to 0%. Applying the command a second time to a partly read book loses the reading progress you had.

Context menu of the table header

Right-clicking the column header of the book list (rather than a row) opens a separate menu with check boxes for every available column (Author, Title, Series, №, Genre, Size, My rating, Added, Type, Collection, Lang, Rating, BookID) — clicking a name turns that column on or off. The Default columns item at the bottom of this menu resets the set of columns and their widths to the program's initial values.

The author, series and genre trees

This menu opens on the trees of the Authors, Series and Genres tabs (on the Genres tab without the last item).

CommandWhat it does
Copy to clipboard Ctrl+CCopies the name of the selected node (the author's name or the series title) to the clipboard.
Add to "Search"Puts the author's name or the series title into the filter field on the Search tab (the item is not shown in the genre tree).

Download list

CommandWhat it does
Go to authorSwitches to the Authors tab and selects the author of the book picked in the queue (switching the active collection first if necessary).
DeleteRemoves the selected entries from the download queue; entries that are downloading at that moment are skipped.
