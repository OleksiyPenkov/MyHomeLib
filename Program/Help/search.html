Пошук книг і фільтри

Вкладка «Пошук» — окремий список книг, який наповнюється не переглядом дерева авторів/серій/жанрів, а довільним набором умов. На відміну від дерев перегляду, тут можна одночасно шукати за кількома полями та зберігати набір умов для повторного використання.

Поля пошуку

Панель ліворуч зібрана з трьох згортних груп.

Книга
Автор, Назва, Серія, Жанр (з кнопкою, що відкриває дерево жанрів для вибору мишею), Ключові слова, Анотація.
Файл
Ім'я, Папка (архів), Тип — тобто розширення файлу.
Різне
Дата додавання (готові інтервали у випадному списку — «сьогодні», «за 3 дні», «за тиждень», «за 2 тижні», «за місяць», «за 3 місяці»), Мова (дволітерний код), зовнішня Оцінка бібліотеки (1–5), прапорці «Приховувати видалені» та «Тільки прочитані».

Простий і розширений пошук

Найпростіший варіант — просто вписати текст у потрібне поле: MyHomeLib шукає його як підрядок без урахування регістру в будь-якому місці значення. Для точнішого запиту те саме поле розуміє й пряму мову умов SQL-подібного вигляду:

  • %текст% — підрядок явно, з можливістю поставити % лише з одного боку;
  • ="точне значення" — точна відповідність;
  • <, >, <> — порівняння (зручно для дати чи розміру);
  • ="ім'я1" OR ="ім'я2" — кілька варіантів в одному полі; саме в такому вигляді в поле «Автор» підставляються кілька авторів, вибраних одразу через пункт «Додати до "Пошуку"» дерева авторів (див. Контекстні меню).

Кнопка праворуч від кожного поля відкриває для нього окреме віконце редагування — зручніше для довгого чи багаторядкового запиту, ніж однорядкове поле. У полі «Жанр» ця сама кнопка замість текстового редактора відкриває дерево жанрів: вибір там підставляє в поле список псевдонімів жанрів замість довільного тексту.

Клавіша Enter у будь-якому полі одразу запускає пошук — так само, як кнопка «Застосувати».

Область пошуку

Пошук виконується лише в межах активної на цей момент колекції. Щоб знайти книгу в іншій підключеній колекції, спершу перемкніться на неї (див. Робота з колекціями), а тоді повторіть пошук.

Пресети

Заповнений набір умов можна зберегти під довільною назвою кнопкою «Зберегти» й потім викликати знову вибором цієї назви зі списку над панеллю пошуку. Кнопка «Видалити» прибирає вибраний пресет зі списку (її підказка — «Видалити пресет»). Кнопка «Очистити» порожнить усі поля, не чіпаючи вибір пресета. Пресети зберігаються в окремому файлі в робочій теці програми й спільні для всіх колекцій.

Ця сторінка замінює довідку про пошук із версії 2011 року і закриває її мертве посилання на неіснуючу тему.
