Читання книг

MyHomeLib сама не показує вміст жодної книги — вона лише каталогізує файли й, за командою «Читати», передає файл зовнішній програмі. Вбудованої читалки в MyHomeLib немає.

Як обирається програма

За розширенням файлу програма шукає у списку Типи файлів і програми для читання призначену читалку. Якщо для розширення читалку налаштовано — запускається саме вона; якщо ні — файл відкривається програмою, яку для цього розширення визначила сама Windows (звичайна файлова асоціація).

Інсталятор кладе поруч із програмою читалку AlReader і під час першого запуску, коли список читалок ще порожній, сам додає її як типову для розширень fb2, doc, txt, htm і html — для PDF, DjVu та деяких інших типова читалка не призначається, і для них одразу використовується асоціація Windows. Але й для AlReader MyHomeLib нічим не відрізняється від будь-якої іншої читалки: вона так само лише запускає її як окрему програму й передає їй шлях до файлу.

Що відбувається під час відкриття

Якщо книга зберігається в архіві (fb2.zip, FBD, запакований не-FB2), MyHomeLib спершу розпаковує потрібний файл у робочу теку «Для читання» під іменем «Автор - Назва» (за потреби скорочуючи його), і відкриває читалкою вже цю копію; якщо файл із таким іменем там уже є з минулого разу, повторно не розпаковує. Незапаковані FB2- і raw-файли відкриваються напряму з теки колекції, без копіювання. Уміст цієї робочої теки можна одним разом прибрати командою «Інструменти» → «Очистити папку "Для читання"».

Якщо книга належить мережевій колекції і ще не завантажена, перед відкриттям MyHomeLib спершу довантажує саме її (короткий проміжний прогрес); якщо довантажити не вдалося, книга не відкривається.

Якщо у налаштуваннях увімкнено параметр «Перезаписувати заголовок fb2», відкриття на читання незапакованого FB2-файлу з власної колекції одразу переписує в самому цьому файлі автора, назву, жанр і серію значеннями з каталогу — це стається з файлом, що лежить у теці колекції, а не з тимчасовою копією. Той самий параметр і той самий запис керують перезаписом заголовка і під час надсилання на пристрій; див. Редагування описів книг і Надсилання книг на пристрій.

Якщо нічого не відкривається

  • Перевірте в розділі Типи файлів і програми для читання, чи вказаний для цього розширення шлях досі існує на диску (переставили чи оновили читалку — шлях міг застаріти).
  • Для книги мережевої колекції переконайтеся, що файл справді завантажено (позначку локальності видно в списку книг) — якщо довантаження щойно не вдалося, спробуйте ще раз через чергу завантажень.
  • Якщо для розширення читалку не призначено, спрацьовує звичайна асоціація Windows — переконайтеся, що для цього типу файлів у системі взагалі є з чим його відкрити.
