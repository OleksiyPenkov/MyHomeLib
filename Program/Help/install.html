Встановлення

Системні вимоги

MyHomeLib — застосунок для Windows, доступний у 32-бітній (x86) і 64-бітній (x64) збірках; для встановлення потрібно вибрати інсталятор під розрядність вашої Windows. Сам інсталятор запускається з правами адміністратора. Усе необхідне для роботи — бібліотека SQLite (sqlite3.dll), вбудована читалка AlReader і списки жанрів — інсталятор кладе поруч із програмою, окремо нічого встановлювати не потрібно.

x86 чи x64

Існує два дистрибутиви: Setup_MyHomeLib_<версія>.exe (32-розрядний) і Setup_MyHomeLib_<версія>_x64.exe (64-розрядний). x64-версія встановлюється лише на 64-бітну Windows; x86-версія працює і на 32-, і на 64-бітній. В усьому іншому обидва інсталятори однакові — та сама тека встановлення за замовчуванням, ті самі ярлики, той самий вибір мови майстра встановлення (English, Українська або Български).

Що інсталятор записує в теку програми, а що — в %APPDATA%\MyHomeLib

За замовчуванням програма встановлюється у стандартну теку Program Files — Program Files\MyHomeLib для x64-версії або Program Files (x86)\MyHomeLib для x86-версії на 64-бітній Windows. Туди інсталятор кладе виконуваний файл MyHomeLib.exe, бібліотеку sqlite3.dll, вбудовану читалку AlReader, конвертери форматів (якщо їх включено в конкретну збірку), списки жанрів, файл довідки, текст ліцензії та ярлик на сайт проєкту.

Окремо інсталятор створює теку %APPDATA%\MyHomeLib (з правом запису для будь-якого користувача Windows) і кладе туди єдиний файл — collections.ini зі списком джерел для оновлення мережевих бібліотек, і лише тоді, коли такого файлу там ще немає. Усе інше в цій теці — налаштування, системна база (Data\user.dbs2, див. Основні терміни) і робочі журнали — створює вже сама програма під час першого й наступних запусків, а не інсталятор; докладніше — у розділі Часті запитання.

Ярлики в меню «Пуск»

Інсталятор створює групу програм із ярликами запуску MyHomeLib, «Довідка MyHomeLib» (відкриває файл довідки; цей напис інсталятор пише українською, хоч би яку мову майстра ви вибрали), «MyHomeLib website» (посилання на домашню сторінку проєкту) і пункт видалення програми. Якщо під час встановлення позначити відповідний прапорець, додатково з'явиться ярлик на робочому столі. Майстер встановлення також дозволяє взагалі не створювати теку в меню «Пуск».

Видалення програми

Видалити MyHomeLib можна ярликом видалення з групи програм у меню «Пуск» або через стандартний список програм Windows — обидва способи запускають той самий деінсталятор.

Деінсталятор прибирає не лише файли з теки програми, а й усю теку %APPDATA%\MyHomeLib, включно з підтекою Data, де лежить системна база user.dbs2. Тобто видалення програми знищує перелік підключених колекцій, групи (зокрема «Обране»), рейтинги й нотатки до книг. Якщо ці дані потрібно зберегти, скопіюйте теку %APPDATA%\MyHomeLib в інше місце ще до видалення.

Самі колекції — файли книг і файл бази .hlc2 — інсталятор і деінсталятор не чіпають: вони лежать там, куди їх поклав користувач під час створення чи підключення колекції (див. Властивості колекції), тому видалення програми на них не впливає.
