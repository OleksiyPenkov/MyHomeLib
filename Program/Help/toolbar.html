Панель інструментів

У MyHomeLib дві панелі інструментів — основна і панель редагування. Обидві можна сховати чи показати через Меню «Вигляд» → «Панелі».

Основна панель інструментів

КнопкаДіяЕквівалент у меню
ЧитатиВідкриває виділену книгу для читання.Книга → Читати (Enter)
Додати до списку завантаженьСтавить виділені (позначені) книги в чергу на завантаження з мережевої колекції.Книга → Додати до списку завантажень (Ctrl+L)
Кнопка з підказкою «Надіслати на пристрій»Копіює виділені книги на пристрій за скриптом за замовчуванням; стрілка розкриває список налаштованих скриптів для вибору іншого.Книга → Надіслати на пристрій
Кирилична абеткаПоказує чи ховає рядок кириличних літер над деревом на вкладках «Автори» і «Серії».Вигляд → Панелі → Кирилична абетка
Латинська абеткаТе саме для латинської абетки.Вигляд → Панелі → Латинська абетка
Кнопка з підказкою «Вибрати колекцію»Розкриває список підключених колекцій для перемикання й пункт створення нової колекції.Колекція → Вибрати колекцію / Створити нову колекцію
Додати в обранеДодає виділені книги до групи «Обране»; стрілка розкриває список інших груп для вибору.Книга → Додати в обране (Ctrl+F у списку книг)
Кнопка з підказкою «Відзначити все»Вмикає чи вимикає позначки (прапорці) в усіх рядках активного списку книг.Контекстне меню списку книг → Відзначити все / Зняти позначки
Кнопка з підказкою «Розгорнути/Згорнути список»Повністю розгортає або згортає активне дерево книг.—
Кнопка з підказкою «Переключити в режим "Таблиця"»Перемикає активний список книг між режимом дерева (з групуванням) і плоскою таблицею.Вигляд → Режим перегляду
Сховати видалені книгиПриховує в списку книги, позначені як видалені.Вигляд → Сховати видалені книги
Показувати тільки завантажені книгиЗалишає в списку лише книги, файли яких уже є на диску.Вигляд → Показувати тільки завантажені книги
Панель інформації про книгуПоказує чи ховає праву панель з обкладинкою, анотацією й описом книги.Вигляд → Панель інформації про книгу
НалаштуванняВідкриває вікно налаштувань програми.Інструменти → Налаштування
Кнопка з підказкою «Довідка»Відкриває цю довідку.Допомога → Довідка

Панель редагування

Ця панель показує текстові кнопки редагування для книги, виділеної в списку.

КнопкаДіяЕквівалент у меню
АвторВідкриває редагування даних автора виділеної книги.Редагування → Автор
Назва серіїВідкриває редагування назви серії.Редагування → Назва серії
Назва жанруВідкриває редагування назви (псевдоніма) жанру.Редагування → Назва жанру
Інформація про книгуВідкриває повне редагування опису книги.Редагування → Інформація про книгу
ВидалитиВидаляє виділену книгу.Книга → Видалити
Перетворити на FBDПеретворює опис не-FB2 книги на файл FBD.Редагування → Перетворити на FBD
Автоматично перетворити на FBDУ поточній збірці кнопка не має обробника — клацання по ній не виконує жодної дії.Редагування → Автоматично перетворити на FBD
