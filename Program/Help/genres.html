Списки жанрів

Дерево жанрів, за яким книги розкладено на вкладці перегляду (див. Перегляд колекції: автори, серії, жанри) і яке пропонується при редагуванні опису книги, береться не з самої колекції, а з окремого файлу списку жанрів.

Два списки: FB2 і не-FB2

Програма постачається з двома готовими списками жанрів, які встановлюються поруч із виконуваним файлом (див. Встановлення):

  • genres_fb2.glst — стандартне дерево жанрів FictionBook, для FB2-колекцій;
  • genres_nonfb2.glst — окреме дерево для колекцій довільних форматів (не-FB2).

Який із них дістає нова колекція — і чи можна замінити його на свій — вирішується під час створення колекції в майстрі, на кроці «Файл опису жанрів» (див. Створення колекції): для FB2-колекцій завжди береться стандартний файл жанрів FB2, а для колекцій довільного формату можна або лишити стандартний файл не-FB2, або вказати свій файл із розширенням .glst.

Оновлення списку жанрів колекції

Команда «Колекція» → «Обслуговування» → «Оновити список жанрів» перечитує файл жанрів наново для активної колекції. Для FB2-колекції це завжди стандартний файл genres_fb2.glst, без запитань. Для колекції довільного формату команда щоразу відкриває діалог вибору файлу — можна вказати той самий файл повторно або інший.

Оновлення повністю замінює список доступних жанрів колекції новим переліком із файлу. Якщо в новому файлі якогось коду жанру, що раніше вже був присвоєний книгам, більше немає, ця позначка жанру в них губиться — сама книга з колекції не зникає, але жанр, якого не стало у файлі, з неї знімається.
