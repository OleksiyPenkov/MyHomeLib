Інтернет і проксі

Ці два розділи діалогу налаштувань (див. Налаштування програми) описано разом, бо обидва стосуються мережевого доступу: «Інтернет» — параметри з'єднання й оновлень, «Проксі» — проксі-сервер, через який ці з'єднання йдуть.

Інтернет: параметри оновлення

Папка з оновленнями
Тека, куди завантажуються файли оновлення бібліотек перед застосуванням. Якщо лишити порожньою або вказати неіснуючу теку, використовується робоча тека програми.
Сервер INPX
Адреса, з якої MyHomeLib бере каталоги INPX під час створення чи оновлення мережевих колекцій (див. Створення колекції й Оновлення колекції); також запасний варіант для завантаження книжки чи рецензії, якщо в самої підключеної колекції немає власної адреси джерела.
Сервер оновлень
Адреса, за якою MyHomeLib перевіряє наявність нової версії самої програми.

Три прапорці нижче керують автоматичними перевірками під час роботи програми:

Перевіряти оновлення бібліотек
Періодично перевіряти, чи є оновлення для підключених мережевих колекцій (типово ввімкнено).
Запускати оновлення бібліотек автоматично
Якщо оновлення бібліотек знайдено — запускати завантаження одразу, без запитання; якщо прапорець вимкнено (типово), програма спершу запитає підтвердження. Не має сенсу без попереднього прапорця.
Перевіряти наявність оновлень програми
Періодично перевіряти вихід нової версії MyHomeLib і повідомляти про це (типово ввімкнено).

Інтернет: параметри з'єднання

Тайм-аут з'єднання (мс)
Скільки чекати на встановлення з'єднання із сервером, перш ніж вважати спробу невдалою.
Тайм-аут читання (мс)
Скільки чекати на відповідь сервера після встановлення з'єднання.
Інтервал (мс)
Пауза між завантаженням окремих файлів у черзі завантажень (див. Завантаження книг) — щоб не навантажувати сервер бібліотеки частими запитами підряд. Типово 0 (без пауз).

Обидва тайм-аути застосовуються до будь-якого звернення MyHomeLib до мережі — завантаження книг, рецензій і перевірки оновлень.

Проксі: основний

Прапорець «Використовувати налаштування Internet Explorer» (типово ввімкнено) — MyHomeLib бере проксі-сервер із системних налаштувань Windows/Internet Explorer автоматично; якщо система повідомляє, що проксі не налаштовано, з'єднання йде прямо, без проксі. Поля нижче («Сервер», «Порт», «Користувач», «Пароль») для ручного налаштування доступні лише тоді, коли цей прапорець вимкнено.

Цей блок (автоматичний чи ручний) використовується для всього мережевого трафіку MyHomeLib, крім того, що описано нижче окремо для оновлень бібліотек.

Проксі: тип

Спадний список «Тип проксі» — HTTP, SOCKS 4 чи SOCKS 5. Це загальне налаштування: той самий тип застосовується як до основного проксі вище, так і до окремого проксі для оновлень нижче — власного вибору типу проксі для оновлень немає.

Проксі для оновлення колекцій

Заголовок цього блоку — «Настройки прокси для обновления коллекций» — у поточній збірці програми не перекладено українською.

Це окремий, повністю самостійний проксі-сервер — використовується лише під час перевірки та завантаження оновлень для мережевих колекцій (і супутніх файлів INPX), а не для завантаження самих книг чи рецензій, яке завжди йде через основний проксі вище. Перемикач «Не використовувати проксі для оновлень» / «Використовувати проксі для оновлень» визначає, чи брати для цього трафіку окремі «Сервер», «Порт», «Користувач» і «Пароль» нижче (поля доступні лише при вибраному другому варіанті), чи з'єднуватися прямо, без проксі (типовий вибір). Налаштування Internet Explorer на цей блок не впливають.
